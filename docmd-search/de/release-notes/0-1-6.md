### Highlights

`docmd-search` v0.1.6 führt erstklassige Unterstützung für die `@docmd/engine-python`-Engine ein und erweitert die Engine-Auflösungs-Pipeline um ein neues `tryImportEngine`-Hilfsprogramm sowie eine erweiterte Fallback-Kette für Python-basierte semantische Indizierung.

### Python-Engine-Integration

- **`@docmd/engine-python` Peer-Abhängigkeit**: `@docmd/engine-python >=0.8.10` wurde als optionale Peer-Abhängigkeit hinzugefügt. Wenn es zusammen mit `docmd-search` installiert wird, wird die Python-Engine automatisch für die Embedding-Generierung und Vektor-Indizierung erkannt und genutzt.
- **`tryImportEngine`-Hilfsprogramm**: Ein neues internes Auflösungs-Hilfsprogramm, das Engine-Module relativ zu `process.cwd()` auflöst und dabei sowohl Monorepo-Arbeitsbereiche als auch Standard-Consumer-Projektlayouts korrekt behandelt.
- **Erweiterte Fallback-Kette**: Die Engine-Auflösungsreihenfolge ist nun `rust → python → js → builtin`.

### Engine API

Die Factory `getEngine()` akzeptiert nun `'python'` als gültige `EngineId`:

```ts
import { getEngine } from 'docmd-search';

const engine = await getEngine({ engine: 'python' });
const index  = await engine.buildIndex(chunks);
```
