### Highlights

`docmd-search` v0.1.5 aktualisiert alle wichtigen Upstream-Toolchains und Laufzeitabhängigkeiten auf die neuesten stabilen Versionen und verbessert damit die plattformübergreifende Prebuild-Kompatibilität sowie die Build-Pipeline-Performance.

### Updates & Upgrades

- **`onnxruntime-node` (^1.29.0)**: Aktualisierte ONNX-Laufzeitumgebung mit verbesserter plattformübergreifender Prebuild-Kompatibilität und WASM-Fallback-Performance.
- **`protobufjs` (^8.8.0)**: Großes Update mit modernen Typdefinitionen und verbesserter Serialisierungsstabilität.
- **`adm-zip` (>=0.6.1)**: Aktualisierte ZIP-Extraktionsroutinen mit den neuesten Sicherheitskorrekturen.
- **`esbuild` (^0.28.2)**: Upgraded Build-Pipeline mit verbessertem Tree-Shaking und ESM-Ausgabetreue.
- **`typescript` (^7.0.2)**: Aktualisierter Compiler mit strengerer Typinferenz und verbesserter Deklarationserzeugung.
- **`@types/node` (^26.5.1)**: Neueste Node.js-Typdeklarationen, ausgerichtet auf die Node 26 LTS-Release-Linie.

### Upgrade

```bash "upgrade"
npm install docmd-search@0.1.5
```
