### Highlights

`docmd-search` v0.1.4 behebt bekannte Schwachstellen in binären Kernabhängigkeiten und stellt plattformübergreifende Prebuild-Kompatibilität auf Apple Silicon und Linux sicher.

### Sicherheits- und Abhängigkeitsverbesserungen

- **`sharp` (^0.35.4)**: Behebt eine kritische Schwachstelle in der mitgelieferten `libheif`-Bildverarbeitungsbibliothek ([GHSA-rgj7-g3m4-5g8c](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c)).
- **`adm-zip` (>=0.6.0)**: Schließt eine Directory-Traversal- und Arbitrary-File-Overwrite-Schwachstelle ([GHSA-955c-w567-g4pw](https://github.com/advisories/GHSA-955c-w567-g4pw)).
- **`protobufjs` (^7.6.5)**: Behebt eine Prototype-Pollution-Schwachstelle ([CVE-2023-36665](https://nvd.nist.gov/vuln/detail/CVE-2023-36665)).
- **`onnxruntime-node` (^1.27.0)**: Stellt native Prebuilds für Node 20/22+ auf Apple Silicon (`darwin-arm64`) und modernen Linux-Distributionen bereit.
- **Explizite Abhängigkeits-Overrides**: Root-Level-Overrides werden nun direkt durchgesetzt, um veraltete oder anfällige Binary-Builds zu verhindern.

### Upgrade

```bash "upgrade"
npm install docmd-search@0.1.4
```
