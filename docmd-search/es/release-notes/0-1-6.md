### Destacados

`docmd-search` v0.1.6 introduce soporte de primera clase para el motor `@docmd/engine-python`, extendiendo la pipeline de resolución de motores con un nuevo utilitario `tryImportEngine` y ampliando la cadena de fallback para cubrir la indexación semántica respaldada por Python.

### Integración del Motor Python

- **Dependencia Peer `@docmd/engine-python`**: Se añadió `@docmd/engine-python >=0.8.10` como dependencia peer opcional. Cuando se instala junto con `docmd-search`, el motor Python se detecta y utiliza automáticamente para la generación de embeddings e indexación vectorial.
- **Utilitario `tryImportEngine`**: Un nuevo utilitario de resolución interno que resuelve módulos de motor relativos a `process.cwd()`, manejando correctamente tanto espacios de trabajo monorepo como diseños de proyectos consumidores estándar.
- **Cadena de Fallback Extendida**: El orden de resolución de motores es ahora `rust → python → js → builtin`.

### Engine API

La factory `getEngine()` ahora acepta `'python'` como `EngineId` válido:

```ts
import { getEngine } from 'docmd-search';

const engine = await getEngine({ engine: 'python' });
const index  = await engine.buildIndex(chunks);
```
