### Destacados

`docmd-search` v0.1.5 actualiza todas las cadenas de herramientas upstream principales y las dependencias de tiempo de ejecución a sus últimas versiones estables, mejorando la compatibilidad de prebuilds multiplataforma y el rendimiento de la pipeline de compilación.

### Actualizaciones y Mejoras

- **`onnxruntime-node` (^1.29.0)**: Motor ONNX actualizado con compatibilidad mejorada de prebuilds multiplataforma y rendimiento de fallback WASM.
- **`protobufjs` (^8.8.0)**: Actualización mayor con definiciones de tipos modernas y estabilidad de serialización mejorada.
- **`adm-zip` (>=0.6.1)**: Rutinas de extracción ZIP actualizadas con las últimas correcciones de seguridad.
- **`esbuild` (^0.28.2)**: Pipeline de compilación actualizada con mejor tree-shaking y fidelidad de salida ESM.
- **`typescript` (^7.0.2)**: Compilador actualizado con inferencia de tipos más estricta y emisión de declaraciones mejorada.
- **`@types/node` (^26.5.1)**: Últimas declaraciones de tipos de Node.js alineadas con la línea de lanzamiento LTS de Node 26.

### Actualización

```bash "upgrade"
npm install docmd-search@0.1.5
```
