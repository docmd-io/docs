**docmd-search** 的首个非 Alpha 发布版本。版本号从 `0.1.0-alpha.0` 升至 `0.1.0`，并发布在 `latest` dist-tag 上。Alpha 版本中引入的语义索引、TUI、浏览器就绪的索引格式以及引擎任务集成保持不变——本次发布主要是打包修复和采用 `docmd` 命名空间。

## 本次发布包含的内容

### Bug 修复

- **`exports` 条件完善。** `package.json#exports` 针对 `.` 和 `./client` 除了 `"import"` 和 `"types"` 外，现在包含了 `"default"` 条件。这解除了在设置 `plugins.search.semantic: true` 时 `@docmd/plugin-search` 的自动安装限制、pnpm 的严格模式安装以及通过 `require('docmd-search')` 导入 `docmd-search` 的 CJS 消费者阻塞。
- **Dist-tag 不再卡在 `alpha`。** 发布的 CI 工作流不再使用 `--tag alpha`；未来的所有版本默认都发布在 `latest`。

### 新增功能

- **`package.json` 中的 `docmd` 命名空间。** 携带该软件包作为 `docmd` 键（类型 `search-engine`）的自我描述，遵循 `docmd@0.8.9` 中针对 `@docmd/plugin-*` 和 `@docmd/template-*` 软件包引入的规范。仅包含元数据；不改变运行时行为。

## 兼容性表

| 层面 | 状态 |
|----------|--------|
| `@docmd/plugin-search@>=0.8.5` | ✓ 可选 Peer 依赖。设置 `plugins.search.semantic: true` 启用。 |
| `@huggingface/transformers@^4.2.0` | ✓ 可选 Peer 依赖，嵌入模型所需。 |
| `onnxruntime-node@^1.26.0` | ✓ 可选 Peer 依赖，设备端推理所需。 |
| Node.js | `>=18` |

## 已知局限性

- 仅支持英文的默认模型
- 无增量更新——任何内容更改后都需要重新完整构建
- 查询期间浏览器内存使用量约为 50–100 MB
- 首次加载较慢，因为需要获取并缓存嵌入模型
