### Destacados

`docmd-search` v0.1.4 corrige vulnerabilidades conocidas en dependencias binarias principales y garantiza la compatibilidad de prebuilds multiplataforma en Apple Silicon y distribuciones Linux modernas.

### Mejoras de Seguridad y Dependencias

- **`sharp` (^0.35.4)**: Corrige una vulnerabilidad de alta severidad en la biblioteca de procesamiento de imágenes `libheif` incluida ([GHSA-rgj7-g3m4-5g8c](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c)).
- **`adm-zip` (>=0.6.0)**: Resuelve una vulnerabilidad de directory traversal y sobreescritura arbitraria de archivos ([GHSA-955c-w567-g4pw](https://github.com/advisories/GHSA-955c-w567-g4pw)).
- **`protobufjs` (^7.6.5)**: Corrige una vulnerabilidad de contaminación de prototipos ([CVE-2023-36665](https://nvd.nist.gov/vuln/detail/CVE-2023-36665)).
- **`onnxruntime-node` (^1.27.0)**: Proporciona prebuilds nativos para Node 20/22+ en Apple Silicon (`darwin-arm64`) y distribuciones Linux modernas.
- **Anulaciones de Dependencias Explícitas**: Las anulaciones a nivel raíz se aplican directamente, evitando que los consumidores descarguen builds binarios obsoletos o vulnerables.

### Actualización

```bash "upgrade"
npm install docmd-search@0.1.4
```
