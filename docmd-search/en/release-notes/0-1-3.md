### Highlights

`docmd-search` v0.1.3 resolves npm package override conflicts during installation and sets explicit minimum version bounds for optional native peer dependencies.

### Package Overrides & Installation Fixes

- **`EOVERRIDE` Fix**: Updated package override syntax to use `$pkg` self-referencing definitions (`$onnxruntime-node`, `$protobufjs`, `$adm-zip`, `$sharp`). This resolves `EOVERRIDE` installation errors when installing `docmd-search` in npm 9+.
- **Peer Dependency Bounds**: Set explicit minimum version bounds (`sharp@>=0.35.0`, `adm-zip@>=0.6.0`, `protobufjs@>=7.6.5`, `onnxruntime-node@>=1.27.0`) in `peerDependencies` to ensure binary compatibility.

### Upgrade

```bash "upgrade"
npm install docmd-search@0.1.3
```
