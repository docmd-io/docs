### Highlights

`docmd-search` v0.1.5 refreshes all core upstream toolchains and runtime dependencies to their latest stable releases, improving cross-platform prebuild compatibility and compiler pipeline performance.

### Updates & Upgrades

- **`onnxruntime-node` (^1.29.0)**: Updated ONNX runtime engine for enhanced cross-platform prebuild compatibility and improved WASM fallback performance.
- **`protobufjs` (^8.8.0)**: Major update bringing modern type definitions and improved serialisation stability.
- **`adm-zip` (>=0.6.1)**: Updated zip extraction routines incorporating the latest upstream security fixes.
- **`esbuild` (^0.28.2)**: Upgraded bundler pipeline with improved tree-shaking and ESM output fidelity.
- **`typescript` (^7.0.2)**: Upgraded compiler with stricter type inference and improved declaration emit.
- **`@types/node` (^26.5.1)**: Latest Node.js type declarations aligned to the Node 26 LTS release line.

### Upgrade

```bash "upgrade"
npm install docmd-search@0.1.5
```
