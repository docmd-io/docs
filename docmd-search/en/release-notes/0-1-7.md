### Highlights

`docmd-search` v0.1.7 is a targeted security and dependency maintenance release. It updates `sharp` to `0.35.5` to resolve a high-severity upstream vulnerability in librsvg and hardens optional peer dependencies.

### Security & Dependency Maintenance

- **Upstream CVE-2026-96889 Patch**: Upgraded `sharp` to `^0.35.5` across development dependencies and `pnpm.overrides`, fully resolving [GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w) in the librsvg image rendering dependency.
- **Hardened Peer Dependencies**: Updated peer dependency boundaries for `sharp (>=0.35.5)`, `adm-zip (>=0.6.1)`, and `protobufjs (>=8.8.0)`, ensuring downstream consumers and build pipelines resolve secure, non-vulnerable packages automatically.
- **Zero-Vulnerability Verification**: Validated the complete 25-check universal failsafe suite (`npm run prep`) with zero audit warnings and full compatibility across the Rust, Python, and JavaScript engine fallbacks.
