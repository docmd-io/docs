### 版本亮点

`docmd-search` v0.1.6 引入了对 `@docmd/engine-python` 引擎的原生支持，通过新的 `tryImportEngine` 工具扩展了引擎解析管线，并拓展了回退链以支持基于 Python 的语义索引。

### Python 引擎集成

- **`@docmd/engine-python` 对等依赖**：将 `@docmd/engine-python >=0.8.10` 添加为可选对等依赖。与 `docmd-search` 一同安装时，Python 引擎将被自动检测并用于嵌入生成和向量索引。
- **`tryImportEngine` 工具**：新的内部解析辅助工具，相对于 `process.cwd()` 解析引擎模块，正确处理 monorepo 工作区和标准消费者项目布局。
- **扩展的回退链**：引擎解析顺序现在为 `rust → python → js → builtin`。

### Engine API

`getEngine()` 工厂现在接受 `'python'` 作为有效的 `EngineId`：

```ts
import { getEngine } from 'docmd-search';

const engine = await getEngine({ engine: 'python' });
const index  = await engine.buildIndex(chunks);
```
