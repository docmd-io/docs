### 版本亮点

`docmd-search` v0.1.5 将所有核心上游工具链和运行时依赖项更新至最新稳定版本，提升跨平台预构建兼容性和构建管线性能。

### 更新与升级

- **`onnxruntime-node` (^1.29.0)**：更新 ONNX 运行时引擎，增强跨平台预构建兼容性和 WASM 回退性能。
- **`protobufjs` (^8.8.0)**：重大更新，带来现代类型定义和改进的序列化稳定性。
- **`adm-zip` (>=0.6.1)**：更新 ZIP 解压例程，包含最新安全修复。
- **`esbuild` (^0.28.2)**：升级构建管线，改善 Tree-Shaking 和 ESM 输出保真度。
- **`typescript` (^7.0.2)**：更新编译器，具有更严格的类型推断和改进的声明生成。
- **`@types/node` (^26.5.1)**：最新 Node.js 类型声明，与 Node 26 LTS 发布线对齐。

### 升级

```bash "upgrade"
npm install docmd-search@0.1.5
```
