### 重点亮点

`docmd-search` v0.1.7 是一个专注安全性与依赖维护的更新版本。它将 `sharp` 升级至 `0.35.5`，彻底修复了 librsvg 中的高危上游安全漏洞，并强化了可选对等依赖边界。

### 安全防护与依赖维护

- **修复上游漏洞 CVE-2026-96889**：将开发依赖与覆盖配置中的 `sharp` 升级至 `^0.35.5`，解决 [GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w) 漏洞风险。
- **强化对等依赖版本规范**：对等依赖版本规范明确为 `sharp (>=0.35.5)`、`adm-zip (>=0.6.1)` 及 `protobufjs (>=8.8.0)`，确保下游消费者自动解析最新安全版本。
- **零安全漏洞验证**：通过完整 25 项全能故障安全测试套件 (`npm run prep`)，0 警告，完全兼容量化向量索引与 Rust、Python、JavaScript 引擎回退管线。
