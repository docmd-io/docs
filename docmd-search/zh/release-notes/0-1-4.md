### 版本亮点

`docmd-search` v0.1.4 修补了核心二进制依赖项中的已知漏洞，并确保在 Apple Silicon 和现代 Linux 发行版上的跨平台预构建兼容性。

### 安全与依赖改进

- **`sharp` (^0.35.4)**：修复了捆绑的 `libheif` 图像处理库中的高危漏洞（[GHSA-rgj7-g3m4-5g8c](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c)）。
- **`adm-zip` (>=0.6.0)**：修复了目录遍历和任意文件覆盖漏洞（[GHSA-955c-w567-g4pw](https://github.com/advisories/GHSA-955c-w567-g4pw)）。
- **`protobufjs` (^7.6.5)**：修复了原型污染漏洞（[CVE-2023-36665](https://nvd.nist.gov/vuln/detail/CVE-2023-36665)）。
- **`onnxruntime-node` (^1.27.0)**：为 Apple Silicon（`darwin-arm64`）和现代 Linux 发行版上的 Node 20/22+ 提供原生预构建。
- **显式依赖覆盖**：直接在根级别强制执行覆盖，防止消费者拉取过时或存在漏洞的二进制构建。

### 升级

```bash "upgrade"
npm install docmd-search@0.1.4
```
