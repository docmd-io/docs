<h1 align="center">Threads v2, Dev Save Deferral & Bridge Reconnect</h1>

<p align="center">
<b>v0.10.2 delivers Threads v2 with draft review workflows, auto-publish countdowns, anchor containers, and author avatars, alongside dev server quiet-window file save deferral and browser bridge reconnect handling.</b>
</p>

## Added

- **Threads v2 Discussion Architecture** (`@docmd/plugin-threads`):
  - **Review Drafts & Staging**: Comments are kept as private per-user drafts stored locally in `.docmd/drafts/` until published, allowing authors and reviewers to draft thoughts without cluttering live Markdown files.
  - **Atomic Publishing**: One-shot atomic publication merges staged drafts into source Markdown files using pure container syntax via the `threads:publish-review` action.
  - **Auto-Publish Mode & Countdown**: Built-in publish widget with configurable countdown timer (`autoPublish.seconds`, default 180s) and automatic staging synchronization after editing quiet periods, or manual collect-and-publish mode.
  - **Syntax Format v2**: Support for anchored quotes (`::: anchor`), author keys (`by <authorKey>`), review identifiers (`review <reviewId>`), parent comment threading (`reply-to <parentId>`), and resolved status markers (`::: thread <id> resolved "<by>" "<date>"`).
  - **Author Profiles & Avatars**: Local author metadata resolution from `.threads/authors.json` for consistent avatar display and identity attribution.
  - **Typed Errors & Option Normalization**: Robust validation for `plugins.threads` configuration (`sidebar`, `autoPublish`) with typed `ThreadsError` error reporting.
  - **Test Runner Integration**: Threads plugin test suites are now integrated directly into the monorepo test runner (`tests/runner.js`), alongside updated Playwright E2E testing specs. Contributed by @svallory in #287, #290, #291, #292, #294.
- **Browser Bridge Reconnect Reload** (`@docmd/ui`): Reloads the page once when the bridge cannot reconnect after having connected, ensuring seamless recovery when dev servers restart or connections drop. Contributed by @svallory in #288.
- **Universal Modal Architecture & Table Lightbox** (`@docmd/ui`, `@docmd/template-summer`):
  - **Universal Modal API (`window.docmd.modal`)**: Introduced a unified, accessible modal manager powered by native HTML5 `<dialog class="docmd-modal">` supporting arbitrary content types (`table`, `image`, custom plugins). Features backdrop light-dismiss, Escape dismissal, focus restoration, and zero hardcoded locale strings.
  - **Table Lightbox Expand**: Large and wide tables now automatically feature a subtle, corner-anchored floating expand button (`.table-expand-button`) outside horizontal scroll wrappers. Clicking opens the table in an expanded modal view (`min(94vw, 1360px)`) with fixed sticky headers (`th`), bi-directional scrolling, and subpixel seam sealing, addressing table header visibility (#295) without page layout interference.
  - **Unified Image Lightbox**: Re-routed image lightbox interactions to use `window.docmd.modal` while preserving backwards compatibility for `.lightbox` and `.image-gallery` configurations.

## Fixed

- **Dev Quiet-Window File Save Deferral** (`@docmd/core`): Fixed file watcher behavior during post-rebuild quiet windows. When a Markdown file save occurs inside the post-rebuild quiet window, the change event is deferred and re-evaluated immediately after the window closes rather than being dropped. Contributed by @svallory in #293.
- **NO_COLOR Test Independence** (`@docmd/core`): Decoupled CLI default-banner assertions from shell `NO_COLOR` and `FORCE_COLOR` environment variables for consistent test execution across local and CI environments. Contributed by @svallory in #289.

## Documentation & Beta Test Suite

- **Threads v2 Plugin Documentation**: Updated `plugins/threads.md` across all 4 locales (`en`, `de`, `es`, `zh`) documenting the v2 container syntax, draft staging, auto-publish options, and RPC actions.
- **Universal Modal & Table Lightbox Documentation**: Updated `content/syntax/index.md`, `content/syntax/images.md`, and `reference/browser-api.md` with complete usage guides and API references for the Universal Modal and table expand lightbox.
- **Beta Test Suite Verification**: Configured Threads v2 with `sidebar: true` and `autoPublish: { seconds: 180, startOn: true }` in the staging environment at `beta-test`, complete with live inline review examples, anchored quotes, reaction containers, and wide 15-column dataset table lightbox testing.
