### Aspectos Destacados

`docmd` v0.9.2 ofrece mejoras significativas para `@docmd/plugin-ai` impulsado por `docmd-assistant` v0.1.11, presentando ejecución determinista de herramientas de múltiples turnos, síntesis de respuestas basada en el contexto, una interfaz rediseñada para bloques de código con encabezados de lenguaje separados y resiliencia en el análisis de flujos para puntos finales de relé.

### Mejoras en el Plugin del Asistente IA (`@docmd/plugin-ai`)

- **Estabilización del Bucle de Ejecución de Herramientas de Múltiples Turnos**: Actualizado a `docmd-assistant` v0.1.11. El motor del asistente ahora preserva de manera determinista el contexto y la intención del usuario a través de múltiples llamadas autónomas a herramientas (p. ej., `search_documentation`, `get_site_structure`), garantizando que el turno final de síntesis se base estrictamente en hechos verificados con enlaces Markdown clicables.
- **Interfaz Moderna de Bloques de Código**: Renderizado rediseñado de bloques de código dentro del chat de IA:
  - Los fragmentos de código están limpiamente encapsulados dentro de un contenedor `.docmd-ai-code-wrap`.
  - Una barra de encabezado de lenguaje aislada (`.docmd-ai-code-header > .docmd-ai-code-lang`) muestra la insignia del lenguaje de programación (p. ej., `bash`, `typescript`, `json`) sin interferir con el comando o texto dentro de `<pre><code>`.
- **Correcciones de Formato Markdown y Envoltorio de Párrafos**: Se corrigió un problema por el cual los marcadores de posición de bloques de código en el formateador Markdown se trataban como texto en línea, eliminando etiquetas `<p>` y `<br/>` innecesarias alrededor de bloques de código y listas.
- **Resiliencia de Flujo HTTP y Respaldo JSON**: El cliente del asistente ahora maneja de manera transparente tanto Server-Sent Events (`text/event-stream`) como respuestas JSON sin streaming de backends de relé, evitando errores de "No response returned" en implementaciones proxy o serverless.
- **Definiciones de Tipos TypeScript**: Tipos implícitos `any` corregidos y firmas de ganchos (hooks) mejoradas en `@docmd/plugin-ai`.

### Paridad Global de Documentación

- **Sincronización Multilingüe**: Todas las notas de versión y guías del asistente se han actualizado 1:1 en español (`es`), inglés (`en`), alemán (`de`) y chino (`zh`).
