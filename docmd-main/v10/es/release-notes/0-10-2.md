<h1 align="center">Threads v2, Sincronización remota Git, Omisión de resaltado y Migración de VitePress</h1>

<p align="center">
<b>v0.10.2 entrega la arquitectura completa de revisión Threads v2, sincronización automática con Git bajo serve, la API programática del plugin Git, omisión de texto plano en lite-hl y mejoras en la migración de VitePress.</b>
</p>

## Added

- **Arquitectura completa Threads v2** (`@docmd/plugin-threads`):
  - **Borradores y preparación**: Los comentarios se almacenan localmente como borradores privados por usuario en `.docmd/drafts/` hasta su publicación, permitiendo redactar revisiones sin alterar los archivos Markdown compartidos.
  - **Publicación atómica**: La publicación atómica en una sola operación transfiere los borradores preparados a los archivos Markdown originales mediante la acción `threads:publish-review`.
  - **Compatibilidad con múltiples bloques de threads**: Conserva y actualiza cada bloque `::: threads` de forma independiente a lo largo del documento (#303, sustituye #298 con agradecimiento a @2648782102).
  - **Aislamiento en subproyectos de workspace**: Almacena diarios de hilos, borradores y perfiles de autor bajo la raíz de documentación de cada subproyecto (`docsRootOf`) en espacios de trabajo multiproyecto (#301).
  - **Flujo de descarte de revisiones**: Permite descartar revisiones en borrador mediante `threads:discard-review`, revirtiendo cambios no confirmados de forma limpia sin corrupción de archivos (#305).
  - **Panel drawer de revisiones e hilos huérfanos**: Interfaz integrada en el panel drawer para gestionar revisiones abiertas, descartadas y publicadas, identificando hilos cuyo texto de ancla haya sido modificado (#306).
  - **Cabeceras de identidad y permisos de rol**: Aplica cabeceras de identidad confiables (`caller.identity`), resolución de correos de autor (`authorEmailHeader`) y permisos durante `docmd serve` (#302).
  - **Sincronización automática con Git en Serve**: Sincronización en vivo con Git para revisiones publicadas y descartadas en `docmd serve`, con reintentos automáticos, ayudantes de credenciales seguros y atribución de confirmaciones (#307).
  - **Límites de longitud de comentarios y de tasa**: Límites de escritura configurables (`maxCommentLength`, `maxCommentsPerMinute`) para proteger contra abusos y garantizar edición concurrente segura (#308).
  - *Cierra #267.*
- **Capa de API programática del plugin Git** (`@docmd/plugin-git`):
  - **Exportación dedicada de API (`@docmd/plugin-git/api`)**: Expone utilidades programáticas independientes y la clase `GitClient` para el núcleo, plugins o scripts externos de CI/CD.
  - **Detección y análisis de proveedores remotos**: Analiza repositorios remotos y detecta GitHub, GitLab (incluidas instancias empresariales autohospedadas), Bitbucket y servidores genéricos vía HTTPS, SSH y SCP.
  - **Generadores canónicos de URL**: Construye automáticamente enlaces de edición, visualización de código, línea de tiempo de historial y confirmaciones en todas las plataformas soportadas.
  - **Ayudantes de tokens y credenciales**: Resuelve tokens de acceso personal en opciones y variables de entorno (`DOCMD_GIT_TOKEN`, `DOCMD_THREADS_GIT_TOKEN`, `GITHUB_TOKEN`, `GITLAB_TOKEN`, `GIT_TOKEN`) usando ayudantes de subshell seguros.
- **Arquitectura de modal universal y lightbox para tablas** (`@docmd/ui`, `@docmd/template-summer`):
  - **API de modal universal (`window.docmd.modal`)**: Gestor modal accesible y unificado basado en el elemento nativo HTML5 `<dialog class="docmd-modal">` para cualquier tipo de contenido con cierre por backdrop, tecla Escape y sin cadenas codificadas rígidamente.
  - **Ampliación de tablas en lightbox**: Las tablas grandes incluyen automáticamente un botón de expansión flotante (`.table-expand-button`) fuera de los contenedores de desplazamiento horizontal con cabeceras fijas (`th`) y desplazamiento bidireccional (#295).

## Fixed

- **Omisión de resaltado en bloques de texto plano** (`@docmd/parser`, `lite-hl` 0.2.2):
  - Los bloques de código sin formato (`plaintext`, `text`, `txt`, `none`, `raw`, `nohighlight`, `no-highlight`) ahora omiten la tokenización, emitiendo texto plano escapado sin spans `hljs-*` ni colores de palabras clave (#299, cierra #297).
  - Actualización del resaltador `lite-hl` a la versión 0.2.2 con omisión nativa y tokenización estructural de Markdown que evita falsos positivos en prosa ordinaria.
- **Mejoras en la migración de VitePress** (`@docmd/core`):
  - **Preservación de subcarpetas**: La migración preserva carpetas anidadas e imágenes al convertir sitios VitePress con diseño raíz (#309).
  - **Detección de configuración TypeScript `.mts`**: Reconoce y analiza automáticamente archivos de configuración `.vitepress/config.mts` (#310).
  - **Rutas de navegación absolutas para MkDocs**: Genera rutas absolutas de sitio (`/guide/`) para que los enlaces anidados resuelvan correctamente (#296).
- **Aplazamiento de guardado durante la ventana de calma** (`@docmd/core`): Procesa adecuadamente las modificaciones de archivos que ocurren durante la ventana posterior a la reconstrucción (#293).
- **Reconexión y recarga del puente del navegador** (`@docmd/ui`): Recarga la página automáticamente tras reconectar (#288).
- **Independencia de NO_COLOR en pruebas** (`@docmd/core`): Desacoplamiento de las variables de entorno `NO_COLOR` y `FORCE_COLOR` (#289).
