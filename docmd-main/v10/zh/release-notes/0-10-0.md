<h1 align="center">生产服务器、静态资源与 MDX</h1>

<p align="center">
<b>v0.10.0 引入了专用的生产环境 HTTP 服务器 (<code>docmd serve</code>)、零配置公共静态根资源管道 (<code>public/</code>)、由 <code>@docmd/lite-mdx</code> 驱动的原生 MDX 组件支持、启动前环境体检诊断 (<code>docmd doctor</code>)，以及跨支持库的生态系统标准化。</b>
</p>

## Added

- **专用生产服务器** (`@docmd/core`)：引入 `docmd serve` 命令，以零文件监听开销运行生产级文档站点。内置 Gzip 和 Deflate 压缩、标准安全响应头 (CSP、HSTS、防嵌套保护)、位于 `/healthz` 的容器存活与就绪探针，以及可配置的主机绑定。Docker 镜像现默认使用 `docmd serve --host 0.0.0.0`。由 @svallory 在 #273 与 #279 中贡献。
- **HTTP 协议可选 MCP 服务** (`@docmd/core`)：在 `docmd serve` 下通过 `POST /mcp` 提供模型上下文协议 (Model Context Protocol) 能力，基于独立于传输协议的 JSON-RPC 处理器，通过 `serve.mcp: true` 与 Token/请求头身份验证进行访问保护。由 @svallory 在 #278 中贡献。
- **生产环境插件动作宿主** (`@docmd/core`, `@docmd/api`)：将插件动作扩展至 `docmd serve`，具备严格的 Origin 白名单和调用者身份准入，防止生产环境下未经授权的上下文写入。由 @svallory 在 #272 与 #277 中贡献。
- **公共静态根资源管道** (`@docmd/core`)：自动识别顶层 `public/` 目录（或通过 `docmd.config.json` 中的 `static` 自定义路径），将文件原样复制到构建根目录，完整保留 `robots.txt`、`favicon.ico`、`CNAME` 与 `.well-known/funding-manifest-urls` 等层级。
- **MDX 组件渲染支持** (`@docmd/plugin-mdx`, `@docmd/lite-mdx`)：通过高性能 `@docmd/lite-mdx` 编译器将一流的 MDX 支持内嵌至核心中，无需额外配置即可在标准 Markdown 中混合编写交互式 JSX 组件。
- **启动前 Doctor 环境体检** (`@docmd/core`, `@docmd/tui`)：新增 `docmd doctor` 命令，通过结构化、彩色终端报告全面校验系统环境、Node.js 版本、引擎依赖、端口占用、模板与插件完整性。
- **动态无头运行标识** (`@docmd/core`)：为 `dev`、`serve` 及测试运行器新增 `--no-open` 命令行参数和 `DOCMD_NO_OPEN=true` 环境变量支持，避免在 CI 与容器等无头环境中触发浏览器弹窗。
- **动态版本回退同步** (`@docmd/parser`, `@docmd/ui`)：在解析器注册表与客户端运行时中实现 `docmd.version` 和 `docmd.buildYear` 的自动回退同步。
- **可选 Iconify 图标插件** (`@docmd/plugin-iconify`)：通过标准 `icon:iconify:<名称>` 语法按需解析并渲染来自 100+ 图标集的 100,000+ 开源图标。

## Improved

- **网络接口绑定** (`@docmd/core`)：为 `docmd dev`、`docmd serve` 和工作区命令新增 `--host <地址>` 参数，本地开发默认绑定更安全的 `127.0.0.1`。由 @svallory 在 #269 中贡献。
- **Playground Web Worker 沙箱隔离** (`@docmd/plugin-playground`)：将代码运行转移到后台 Web Worker，防止耗时或死循环脚本冻结浏览器 UI 主线程。
- **构建产物工作区整洁度**：确保 `pnpm -r run build` 隔离临时文件并保持 Git 工作区整洁。由 @svallory 在 #275 中贡献。
- **测试套件独立环境隔离**：为每个测试进程分配独立的临时工作根目录，彻底避免并发竞争。由 @svallory 在 #276 中贡献。
- **生态元数据与赞助标准化**：统一内部插件的关键词、规范化 README 编写，并将所有代码仓库与赞助清单统一对齐至 `https://docmd.io` 与 `docmd-io` 组织。

## Fixed

- **SPA 导航中 Body 内联脚本重复执行** (`@docmd/ui`)：防止单页应用客户端路由重复运行页面内脚本，避免 DOM 混乱与事件多次绑定。由 @MSOB7YY 在 #270 中贡献。
- **Highlight.js 主题加载闪烁** (`@docmd/ui`, `@docmd/template-summer`)：首次加载页面时即时应用语法高亮样式，消除水合期间的代码闪烁。由 @MSOB7YY 在 #270 中贡献。
- **非索引文件夹相对链接解析** (`@docmd/parser`)：修复深层嵌套页面中指向无末尾斜杠目录的相对链接寻址异常。由 @GPT-AGI 在 #271 中贡献。
- **Gitignore 祖先目录过度匹配** (`@docmd/core`)：将无前缀 gitignore 规则限制在其父目录内，避免祖先目录规则错误忽略项目源文件。由 @svallory 在 #274 中贡献。
- **MCP 路径遍历防御加固** (`@docmd/core`)：严格将 `read_doc` 与 `list_docs` 限制在配置的源码目录 Markdown 文件范围内，杜绝符号链接逃逸。由 @svallory 在 #268 中贡献。
- **面包屑导航 Schema 回退** (`@docmd/plugin-seo`)：修复 JSON-LD 面包屑结构化数据中缺失中间层级的问题，提供自愈式层级补全。

## Security & Maintenance

- Playground HTML 预览在不包含 `allow-same-origin` 的隔离沙箱 iframe 中执行。
- 生产服务器安全响应头：`docmd serve` 默认强制开启 CSP、HSTS、X-Content-Type-Options 与 Frame-Options 安全标头。
- WebSocket Origin 校验：强制执行严格的来源白名单，在动作宿主执行期间屏蔽不可信消息。
- 在 PR #281 中升级 `docker/login-action` 至 4.8.0。
- 在 PR #282 中升级工作区运行时依赖。
