<h1 align="center">Threads v2、开发服务器保存延迟与 Bridge 重新连接</h1>

<p align="center">
<b>v0.10.2 带来了 Threads v2 讨论架构（包含草稿评审工作流、自动发布倒计时、锚点引用容器与作者头像），并优化了开发服务器平静期文件保存延迟处理与浏览器 Bridge 断线重连机制。</b>
</p>

## Added

- **Threads v2 讨论架构** (`@docmd/plugin-threads`):
  - **评审草稿与暂存**：评论作为私有的单用户草稿保存在本地 `.docmd/drafts/` 中，直到显式发布，避免在草稿起草阶段污染共享的 Markdown 源码文件。
  - **原子化发布**：通过 `threads:publish-review` 动作单次将暂存草稿原子化合并到源 Markdown 文件中。
  - **自动发布模式与倒计时**：内置发布挂件，支持可配置的倒计时定时器（`autoPublish.seconds`，默认 180 秒）并在编辑静默期后自动同步暂存，或切换为手动汇总发布模式。
  - **语法格式 v2**：支持锚点引用（`::: anchor`）、作者键（`by <authorKey>`）、评审标识符（`review <reviewId>`）、层级回复（`reply-to <parentId>`）与解决状态标记（`::: thread <id> resolved "<by>" "<date>"`）。
  - **作者配置与头像**：支持从 `.threads/authors.json` 本地解析作者元数据，展示作者头像与身份归属。
  - **类型化错误与选项规范化**：针对 `plugins.threads`（`sidebar`、`autoPublish`）提供类型校验，并使用 `ThreadsError` 提供精准错误提示。
  - **测试运行器集成**：Threads 插件测试套件直接集成至根测试运行器（`tests/runner.js`），并同步更新了 Playwright E2E 测试规范。由 @svallory 在 #287, #290, #291, #292, #294 中贡献。
- **Browser Bridge 重连刷新** (`@docmd/ui`): 在开发服务器重启或连接中断重新恢复后自动刷新页面一次，确保客户端状态无缝恢复。由 @svallory 在 #288 中贡献。
- **通用模态框架构与表格 Lightbox 放大视图** (`@docmd/ui`, `@docmd/template-summer`):
  - **通用模态框 API (`window.docmd.modal`)**：基于原生 HTML5 `<dialog class="docmd-modal">` 构建的无障碍通用模态框管理器，支持任意内容类型（`table`、`image`、自定义插件），具备遮罩点击关闭、Escape 快捷键关闭、焦点自动还原与无硬编码语言文本特性。
  - **表格 Lightbox 放大视图**：超宽与大型表格自动在右上角外层悬浮定位精致的展开按钮（`.table-expand-button`，不随横向滚动条滑动），点击即可展开至自适应弹窗视图，原生支持垂直粘性表头（`th`）与双向滚动（#295）。
  - **统一步调的图片 Lightbox**：现有 `.lightbox` 图片点击查看功能现已无缝统一至通用模态框架构中，完全兼容现有配置。

## Fixed

- **开发服务器平静期文件保存延迟处理** (`@docmd/core`): 修复了构建完成后平静期内的文件监听行为。当在重建平静期内发生 Markdown 文件保存时，变更事件会被延迟并在平静期结束后立即重新处理，而不是被直接丢弃。由 @svallory 在 #293 中贡献。
- **NO_COLOR 测试环境独立性** (`@docmd/core`): 解耦了 CLI 默认横幅断言与终端环境变量 `NO_COLOR` 及 `FORCE_COLOR` 的依赖。由 @svallory 在 #289 中贡献。

## Documentation & Beta Test Suite

- **Threads v2 插件文档**：在所有四种语言（`en`、`de`、`es`、`zh`）的 `plugins/threads.md` 中全面更新了 v2 容器语法、草稿暂存工作流、自动发布配置与 RPC 动作说明。
- **通用模态框与表格文档**：在 `content/syntax/index.md`、`content/syntax/images.md` 与 `reference/browser-api.md` 中全面补充了通用模态框 API 与表格 Lightbox 放大视图的开发者指南与参考文档。
- **Beta 测试套件验证**：在 `beta-test` 预发布测试套件中配置了 Threads v2（`sidebar: true` 与 `autoPublish: { seconds: 180, startOn: true }`），并在 15 列超大表格场景下验证了 Lightbox 模态框双向滚动与粘性表头特性。
