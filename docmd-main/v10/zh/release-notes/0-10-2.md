<h1 align="center">Threads v2、Git 远程同步、纯文本高亮绕过与 VitePress 迁移</h1>

<p align="center">
<b>v0.10.2 带来了完整的 Threads v2 评审架构、serve 模式下的自动化 Git 同步、核心 Git 插件编程式 API、lite-hl 纯文本代码块原生绕过与 VitePress 迁移增强。</b>
</p>

## Added

- **Threads v2 完整讨论架构** (`@docmd/plugin-threads`):
  - **评审草稿与暂存**：评论作为私有的单用户草稿保存在本地 `.docmd/drafts/` 中，直到显式发布，避免在草稿起草阶段污染共享的 Markdown 源码文件。
  - **原子化发布**：通过 `threads:publish-review` 动作单次将暂存草稿原子化合并到源 Markdown 文件中。
  - **多线程块独立解析与发布**：支持并在文档多个独立章节中维护各自的 `::: threads` 容器块（#303，取代 #298，致谢 @2648782102）。
  - **工作区子项目文档根目录隔离**：在多项目工作区环境中，将评论日志、草稿与作者数据安全隔离在各子项目的文档根目录下（`docsRootOf`，#301）。
  - **放弃评审工作流**：支持通过 `threads:discard-review` 安全放弃草稿评审，无残留地还原未提交的本地状态（#305）。
  - **评审抽屉面板与孤立线程标记**：抽屉面板中整合全功能评审管理 UI，汇总显示进行中、已放弃与已发布的评审，并智能标记由于上游内容删除导致的孤立线程（#306）。
  - **调用者身份标头与权限控制**：在 `docmd serve` 模式下严格校验受信任调用者身份（`caller.identity`）、作者邮箱解析标头（`authorEmailHeader`）与操作权限（#302）。
  - **Serve 模式自动化 Git 同步**：发布与放弃评审时在 `docmd serve` 运行期自动执行远程 Git 拉取与推送，具备重试退避机制、子进程环境变量凭据助手与机器人 Committer 署名（#307）。
  - **评论长度与频率限制**：内置可配置的写入安全限制（`maxCommentLength`、`maxCommentsPerMinute`），保障并发评审与防止滥用（#308）。
  - *关闭 #267。*
- **核心 Git 插件编程式 API 层** (`@docmd/plugin-git`):
  - **独立 API 导出 (`@docmd/plugin-git/api`)**：为核心系统、插件或 CI/CD 自动化脚本提供独立的编程式 Git 工具集与 `GitClient` 客户端类。
  - **远程仓库提供商智能解析**：自动解析仓库 Remote 地址，通过 HTTPS、SSH 和 SCP 格式识别 GitHub、GitLab（包含自建企业版实例）、Bitbucket 与通用 Git 平台。
  - **规范化 URL 生成器**：一键生成符合对应平台规范的源码编辑、文件查看、提交时间线与 Commit 链接。
  - **访问令牌与凭据助手**：按优先级安全解析个人访问令牌（`DOCMD_GIT_TOKEN`、`DOCMD_THREADS_GIT_TOKEN`、`GITHUB_TOKEN`、`GITLAB_TOKEN`、`GIT_TOKEN`），使用子进程环境凭据助手防止凭据暴露。
- **通用模态框架构与表格 Lightbox 放大视图** (`@docmd/ui`, `@docmd/template-summer`):
  - **通用模态框 API (`window.docmd.modal`)**：基于原生 HTML5 `<dialog class="docmd-modal">` 构建的无障碍通用模态框管理器，支持任意内容类型（`table`、`image`、自定义插件），具备遮罩点击关闭、Escape 快捷键关闭与无硬编码语言文本特性。
  - **表格 Lightbox 放大视图**：超宽表格自动在右上角外层悬浮定位展开按钮（`.table-expand-button`），点击即可展开至弹窗视图，原生支持垂直粘性表头（`th`）与双向滚动（#295）。

## Fixed

- **纯文本代码块语法高亮原生绕过** (`@docmd/parser`, `lite-hl` 0.2.2):
  - 纯文本代码块围栏标识（`plaintext`、`text`、`txt`、`none`、`raw`、`nohighlight`、`no-highlight`）现在完全绕过语法分析，直接渲染为未修饰的转义文本，不再注入伪关键词高亮标签与主题配色（#299，关闭 #297）。
  - 升级自定义高亮库 `lite-hl` 至 0.2.2，支持原生纯文本绕过与 Markdown 结构化高亮，彻底杜绝英语普通词汇被误判为编程语言关键字。
- **VitePress 迁移功能增强** (`@docmd/core`):
  - **嵌套资源子目录完整保留**：转换根布局的 VitePress 项目时，自动完整复制嵌套子文件夹及图片等资源（#309）。
  - **TypeScript `.mts` 配置文件识别**：自动检测并解析 `.vitepress/config.mts` 配置文件（#310）。
  - **MkDocs 站点绝对导航路径**：修复 MkDocs 迁移生成的站点绝对路径（`/guide/`），确保深层嵌套页面链接正常解析（#296）。
- **Git 客户端与 Threads 安全加固** (`@docmd/plugin-git`, `@docmd/plugin-threads`):
  - 加固远程 URL 验证以防御多项式 ReDoS（CWE-1333），并在 CLI 命令执行中使用 `--` 选项分隔符防止二阶参数注入（CWE-88）。
  - 关闭 GitHub CodeQL 代码扫描告警 #151, #152, #153 与 #154。
- **Threads UI 与侧边栏布局现代化** (`@docmd/plugin-threads`):
  - 侧边栏 FAB 凸起完全贴合屏幕右边缘，悬停时平滑外扩。
  - 打开 Threads 抽屉面板时自动隐藏页面目录（`body.tc-panel-open`），为主内容提供更宽阔的无干扰阅读区域。
  - 评论时间戳根据访客浏览器语言本地化，并在原生悬停时提供完整 ISO UTC 工具提示。
  - 优化页内讨论卡片样式，仅作者可见删除图标，采用具有明确含义的状态边框颜色，并保持表情符号反应稳定。
- **开发服务器平静期文件保存延迟处理** (`@docmd/core`): 修复了构建完成后平静期内的文件监听行为，延迟处理平静期内发生的 Markdown 保存事件（#293）。
- **Browser Bridge 重连刷新** (`@docmd/ui`): 在开发服务器重启或连接中断重新恢复后自动刷新页面一次（#288）。
- **NO_COLOR 测试环境独立性** (`@docmd/core`): 解耦了 CLI 默认横幅断言与终端环境变量 `NO_COLOR` 及 `FORCE_COLOR` 的依赖（#289）。
