Nos complace anunciar la llegada de **docmd v0.9.0**, una actualización mayor enfocada en capacidades de IA de última generación, rendimiento extremo del compilador y soporte multi-proyecto.

## Aspectos Destacados de la Versión

::: grids
    ::: grid
        ::: card "Asistente de IA Integrado" icon:bot
        Respuestas en tiempo real dentro de su sitio de documentación gracias al nuevo `@docmd/plugin-ai` con soporte RAG local y proveedores como OpenAI, Anthropic y Ollama.
        :::
    :::
    ::: grid
        ::: card "Motor en Rust (Vista Previa)" icon:cpu
        Rendimiento de compilación hasta 10 veces más rápido para grandes repositorios de documentación mediante el nuevo núcleo en Rust.
        :::
    :::
    ::: grid
        ::: card "Paquetes de Conocimiento OKF" icon:share-2
        Exporte su conocimiento técnico en formato Open Knowledge Format (OKF) para consumo directo por agentes de desarrollo.
        :::
    :::
:::

## Cómo Actualizar

Actualice a la última versión ejecutando:

```bash
npx @docmd/core migrate --upgrade
```

::: callout tip "Actualización Automática de Configuración" icon:sparkles
El comando de migración actualizará automáticamente su archivo `docmd.config.json` al nuevo esquema de la versión v0.9.0 sin romper su estructura actual.
:::
