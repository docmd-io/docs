### 版本亮点

`docmd` v0.9.9 带来了全新的**变量与个性化运行时引擎**，打通了构建期静态模板插值与客户端响应式个性化会话；修复了多版本部署在 `/vX.Y.Z/` 路径下的搜索索引加载问题；消除了模板布局槽警告并加固了 Monorepo 依赖安装；完善了 SPA Logo 外部链接路由跳转；并针对 AI 助手插件优化了文档上下文检索与工具调用链路。

- **统一变量与个性化引擎 (`@docmd/core`, `@docmd/parser`, `@docmd/ui`)**：支持在 Markdown 正文、公告横幅与页脚版权中优雅使用 `{{ variable }}` 插值。提供丰富的零配置内置系统变量（`docmd.version`、`docmd.buildYear`、`docmd.gitCommit`、`docmd.gitBranch`、`page.slug`、`page.title`），支持 `||` 默认回退值以及 `\{{ ... }}` 语法转义。
- **交互式 Playground 核心插件 (`@docmd/plugin-playground`)**：默认随核心包分发的免配置插件。支持直接运行 JavaScript 代码、直接引用代码库脚本源文件（`::: playground src="..." /:::`）、交互式 Live / Code 视图标签切换（`tabs`）、HTML/CSS 组件实时预览、格式化控制台输出拦截、缺失文件优雅告警提示，并与 `docmd-runtime` 无缝响应联动，未引用的静态页面零额外静态资源消耗。
- **通用客户端轻量运行时 (`@docmd/ui`)**：在所有模板中默认集成 `docmd-runtime.js`。提供全局 `window.docmd` API，通过响应式 DOM 标记（`<span data-docmd-var="...">`）实现代码块中个人 API Key 的动态水合与无刷新更新，并支持 iFrame 跨窗口 `postMessage` 状态同步。
- **版本化搜索路径解析修复 (`@docmd/plugin-search`)**：修复了基准路径以版本号结尾（例如 `/docs/v1.2.3/`）时搜索索引加载失败的问题（感谢 @Goldloli 提交的 PR #266，解决 #262）。
- **SPA 外部 Logo 跳转修复 (`@docmd/ui`)**：修复了点击指向外部域名或主站的 Logo 时被 SPA 客户端路由意外拦截报错的问题。
- **模板解析器与依赖隔离加固 (`@docmd/api`, `@docmd/ui`)**：彻底消除了诸如 `summer` 等扩展模板在多项目开发中出现的布局槽未找到警告，并在预检阶段优化了 npm v7+ 的依赖剔除防范机制。
- **AI 助手工具链与检索优化 (`@docmd/plugin-ai`)**：优化了文档检索与引用合成流程，以更少的往返交互实现精准文档引用。
