### 亮点

`docmd` v0.9.4 带来了 OpenAPI 暗黑模式配色修复（[Issue #207](https://github.com/docmd-io/docmd/issues/207), [PR #208](https://github.com/docmd-io/docmd/pull/208)）、严格的 AI 助手配置禁用保障（[Issue #209](https://github.com/docmd-io/docmd/issues/209)）、基于 `docmd-assistant` v0.1.15 的回复净化与恢复、多核并行集成测试运行器以及维护流水线（`pnpm prep`）的大幅加速。

### OpenAPI 插件暗黑模式修复 (`@docmd/plugin-openapi`)

- **暗黑配色覆盖 ([Issue #207](https://github.com/docmd-io/docmd/issues/207), [PR #208](https://github.com/docmd-io/docmd/pull/208))**：修复了 OpenAPI 接口容器 (`.oa-operation`)、Schema 表格 (`.oa-schema-table`)、参数说明与响应详情在暗黑模式下的背景颜色，使其完美继承站点的深色主题。由 [@w666](https://github.com/w666) 贡献。
- **视觉一致性**：Schema 表格与模型定义在暗黑模式下与文档整体设计浑然一体，彻底消除不协调的白色背景。

### AI 助手插件与引擎 (`@docmd/plugin-ai` & `docmd-assistant` v0.1.15)

- **严格配置禁用 ([Issue #209](https://github.com/docmd-io/docmd/issues/209))**：修复了在 `docmd.config.json` 中配置 `plugins.ai.assistant: false` 或 `plugins.ai.enabled: false` 时仍向 HTML 注入脚本与样式的问题。禁用状态下将严格不生成任何 AI 资源与标签。
- **升级至 docmd-assistant v0.1.15**：解决了多轮对话中有效回答被误截断的问题，确保自然语言解答完整保留。

### 测试运行器与流水线性能加速

- **多核并行测试执行**：重构 `tests/runner.js`，实现多个外部集成测试套件跨 CPU 核心并发执行，使测试耗时减少约 65%。
- **确定性构建缓存**：修复了缓存存储目录创建逻辑，并将输出目录（`site/`、`_site/`）排除在快照哈希之外，实现近 100% 的缓存命中率。
- **流水线优化 (`pnpm prep`)**：消除了冗余的 `node_modules` 清理与重复测试步骤，将 `pnpm prep` 耗时从约 4.7 分钟缩短至约 1.3 分钟（提速约 3.4 倍）。
- **标准化模拟器 TUI (`pnpm sim`)**：统一使用方括号状态标识（`[ DONE ]`、`[ WAIT ]`、`[ INFO ]`）。

### 已解决的 Issue 与 Pull Request

- **[Issue #207](https://github.com/docmd-io/docmd/issues/207)** / **[PR #208](https://github.com/docmd-io/docmd/pull/208)**：修复 OpenAPI 在暗黑模式下的渲染样式（由 [@w666](https://github.com/w666) 贡献）。
- **[Issue #209](https://github.com/docmd-io/docmd/issues/209)**：`@docmd/plugin-ai`：`assistant: false` 未能禁用 AI 挂件（getAssets 忽略了禁用标志）。

### 全球多语言文档同步

- **多语言一致性**：在英语 (`en`)、德语 (`de`)、西班牙语 (`es`) 和中文 (`zh`) 之间完全同步了发行说明与导航树。
