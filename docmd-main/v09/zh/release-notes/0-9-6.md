### 核心亮点

`docmd` v0.9.6 隆重推出旗舰级**专注模式**（Zen Mode），提供右上角专属**打印**与**浅色/深色主题**切换控制的无干扰沉浸式阅读体验，并在文档复制组件中直接整合专属**打印**操作，同时针对语义搜索与核心依赖项完成了关键安全漏洞（CVE）修复，为 AI 助手引擎引入多轮深度推理流式更新，支持通过 `.gitignore` 和 `config.exclude` 过滤草稿及忽略内容，修复了导航属性转义以及插件重载 Hook。

### 专注模式与打印控制 (`@docmd/ui` & `@docmd/template-summer`)

- **无干扰沉浸式阅读**：只需在选项菜单中一次点击或使用键盘快捷键（`Alt+F` / Option+F），所有导航侧边栏、标头、目录、面包屑、页脚和悬浮工具均会平滑隐退。正文居中呈现并提供符合人机工程学的理想排版行宽，助力技术文档的深度阅读。
- **右上角专属控制栏**：在专注模式下，右上角浮动工具栏仅保留三项最核心的操作控制：
  1. **打印页面**（`printer` 图标，调用 `window.print()` 并应用专为纸张与 PDF 导出量身定制的无杂质打印样式表）。
  2. **浅色 / 深色模式切换**（在专注阅读时依然能够随时无缝切换全局主题）。
  3. **退出专注模式**（`minimize-2` 图标，或按下 `Esc` / `Alt+F` 键即可瞬间恢复常规布局）。
- **文档复制组件中的打印按钮**：当启用打印时（`layout.print: true`、`layout.optionsMenu.components.print: true` 或 `layout.copyWidgets.print: true`），文档标头处将直接在“复制 Markdown”和“复制上下文”按钮旁呈现专属的“打印”按钮。
- **专业级打印样式表**：内置 `@media print` 规则，确保打印文档或导出为 PDF 时自动剥离所有网页导航与界面杂物，生成排版整洁、清晰美观的纸质文档。
- **跨模板原生支持**：在默认 `@docmd/ui` 模板与 `@docmd/template-summer` 现代布局中均开箱即用。
- **灵活的选项菜单配置**：`optionsMenu.components.focusMode` 与 `optionsMenu.components.print` 可直接在 `docmd.config.json` 的 `layout.optionsMenu.components` 中轻松配置。

### 安全审计与依赖项 CVE 修复

- **关键 CVE 补丁**：
  - **`sharp` (`^0.35.4`)**：修复了与捆绑的 `libheif` 相关的严重安全通告（[GHSA-rgj7-g3m4-5g8c](https://github.com/advisories/GHSA-rgj7-g3m4-5g8c) / Alert #40）。
  - **`adm-zip` (`>=0.6.0`)**：彻底解决了路径遍历及任意文件覆盖漏洞（[GHSA-955c-w567-g4pw](https://github.com/advisories/GHSA-955c-w567-g4pw) / Alert #39）。
  - **`protobufjs` (`^7.6.5`)**：修复了原型污染漏洞（[CVE-2023-36665](https://github.com/advisories/GHSA-h755-8qp9-cq85)）。
  - **`onnxruntime-node` (`^1.27.0`)**：升级以支持 Apple Silicon (`darwin-arm64`) 与现代 Linux 系统上 Node 20/22+ 的开箱即用原生预编译。
- **流水线自动化安全审计**：`tools/prep.js` 现在会在构建前自动运行安全审计（`pnpm audit --audit-level=high`），防止包含高危或严重漏洞的代码被打包或发布。
- **`docmd-search` 依赖版本锁定**：通过显式包覆写（overrides）与 peerDependencies 约束，确保终端用户永远不会安装过时或存在安全风险的二进制库。

### 文件排除与 Git Ignore 过滤 ([#226](https://github.com/docmd-io/docmd/issues/226))

- **项目级排除规则**：新增对 `config.exclude` Glob 匹配规则的支持，允许文档作者在构建时排除草稿页面、内部笔记和临时文件。
- **自动遵循 `.gitignore`**：内置树遍历 `.gitignore` 解析器，自动将忽略的 Markdown 文件和目录从 HTML 编译及语义搜索向量化中剔除。

### 导航属性与 SPA 链接规范化 ([#227](https://github.com/docmd-io/docmd/issues/227))

- **非转义导航属性**：修复了侧边栏导航模板中的 EJS 属性转义（改用 `<%-` 而非 `<%=`），确保自定义数据属性与链接属性完整正确渲染。
- **强化客户端路由器**：悬浮预加载与 SPA 页面跳转自动去除 `href` 属性中意外包裹的多余引号，并精准识别 `target="_blank"` 与 `rel="noopener"`。

### AI 助手多轮推理流式更新与消息操作 ([#228](https://github.com/docmd-io/docmd/issues/228))

- **扩展多轮推理预算**：将内部对话推理轮数上限扩展至 6 轮，确保多步工具检索（例如检查结构、核对页面等）在最终合成回答前充分执行。
- **实时流式替换协议**：实现流式替换协议（`meta.replace: true`），在多轮思考迭代中即时流式输出 SSE Token，同时避免残留未完成的工具调用标记。
- **架构级兜底合成机制**：当检索未直接命中专属文档页面时，提供多级上下文备用合成器，基于全局架构与约定给出精准指导。
- **可配置的消息操作按钮**：`@docmd/plugin-ai` 中的消息操作控件（复制回答、重试、编辑输入）可通过 `config.plugins.ai.messageActions: true` 按需启用（默认保持为 `false`）。

### 插件系统重载修复 ([PR #229](https://github.com/docmd-io/docmd/pull/229))

- **实时重载实例同步**：解决了 `packages/api/src/hooks.ts` 中在实时开发模式下重新加载插件配置未将新模块赋值给 `rawModule`、导致旧 Hook 持续残留的问题。
