### 版本亮点

`docmd` v0.9.1 带来了一项重大的容器引擎现代升级：引入了标准化的显式容器闭合标签、显式的键值对头部属性、末尾 `# 注释` 支持、原生的 `::: mermaid` 图表容器、彻底解决了 Issue #187（noStyle 模式下 HTML 块内部空行中断解析）问题，并实现了所有支持语言（`en`、`de`、`es`、`zh`）1:1 的完整文档对齐。

### 容器引擎标准化

- **显式闭合标签**：在所有结构化容器中统一了显式的闭合标签（`::: container` ... `::: /container`），实现了确定的块解析与无限嵌套深度。
- **统一的子容器命名规范**：引入了具名子容器元素（`::: tabs` 内使用 `::: tab` ... `::: /tab`，`::: steps` 内使用 `::: step` ... `::: /step`，`::: changelog` 内使用 `::: log` ... `::: /log`）。原有标记（`== tab`、`1.`）保留完全向下兼容支持。
- **显式键值对格式**：在容器头部统一了具名参数语法（`title:"..."`、`url:"..."`、`align:center`、`zoom:true`、`icon:name`），同时保留位置参数的回退机制。
- **容器头部注释**：原生支持在容器开启和闭合行末尾使用 `# 注释`（如 `::: tabs # 头部注释`、`::: /tabs # 闭合注释`）。
- **自闭合容器规范化器与灵活闭合标签**：增强了自闭合容器（`::: button`、`::: tag`、`::: embed`）的嵌套深度追踪、段落行内嵌入能力与孤立标签自动剥离。用户既可在独立行或段落中间直接使用自闭合容器，也可灵活添加显式闭合标签（`::: /button`、`::: /tag`）。
- **新增提示工具容器 (`::: tip`)**：引入了原生的交互式悬浮提示框（`::: tip "悬浮说明" term:"术语" ::: /tip`），支持行内与块级术语悬浮弹出框渲染。

### 原生 `::: mermaid` 图表容器

- **丰富的高级 UI 容器**：引入了专用 `::: mermaid` 容器，将图表 DSL 封装在交互式 UI 壳中，支持自定义标题、图标、对齐方式（`left`、`center`、`right`）、内置主题覆盖（`default`、`dark`、`forest`、`neutral`）以及平移与缩放控件。
- **插件绑定执行架构**：直接由 `@docmd/plugin-mermaid` 驱动。若在 `docmd.config.json` 中禁用该插件，`::: mermaid` 容器与标准代码块解析均将被无缝停用，且不会在客户端注入任何 JS 静态资源。
- **混合 GFM 兼容性**：标准 Markdown 代码块（```` ```mermaid ````）保持 100% 支持，确保在 GitHub 与 IDE 预览窗口中的通用兼容性。

### AI 助手功能增强与导航工具

- **新增 `get_site_structure` 工具**：为 `@docmd/plugin-ai` 装备了结构检查工具 (`get_site_structure`)，使 AI 助手能够直接获取网站的完整版本清单（当前版本与历史版本）、支持的语言/区域设置、多项目工作区配置以及带有标题和 URL 的完整页面导航树。
- **动态搜索能力检测**：AI 助手现在会自动读取 `@docmd/plugin-search` 的构建元数据 (`searchCapabilities: { keyword: true, semantic: Boolean }`)，从而动态判断语义向量搜索是否已启用，或是仅启用了全文关键词搜索 (MiniSearch)。
- **关键词与语义查询优化**：更新了 AI 助手的提示词路由与工具调用指令，在调用 `search_documentation` 时会自动将查询词格式化为简洁的高精度关键词（如 `"containers hero"`），既能避免在关键词搜索引擎中出现低精度匹配，又能最大化语义索引的匹配效果。

### 引擎与 Bug 修复

- **HTML 块中的空行处理 (Issue #187)**：修复了在 `noStyle` 页面或标准 Markdown 文件中，HTML 元素之间的空行导致后续 HTML 元素被渲染为未经解析的纯文本的问题。
- **Zero-Config SPA 首页导航链接保留 (Issue #196)**：修复了在单页应用（SPA）过渡后侧边栏同步时，将零配置模式下的根首页链接（`<a href="">`）误转换为 `<a href="#">` 导致无法点击返回文档根目录的问题。
- **Summer 模板公告栏渲染修复**：修复了 `@docmd/template-summer` 中基于对象的公告栏配置（包含 Markdown 格式化文本、类型变体、链接、图标及关闭按钮）无法正确显示文本和组件的问题。

### 全局文档完全同步

- **多语言 1:1 对齐**：全量更新并对齐了英文（`en`）、德文（`de`）、西班牙文（`es`）和中文（`zh`）下所有的文档页面、容器指南与代码示例。
