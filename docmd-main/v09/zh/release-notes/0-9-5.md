### 亮点

`docmd` v0.9.5 带来了功能强大的 AI 助手自主工具套件与扩容上下文窗口、多项目工作区 OpenAPI 规范智能发现、Inline 内联规范渲染、Threads 协作插件对 Summer 主题的原生适配以及错误诊断优化。

### AI 助手智能体工具与上下文扩容 (`@docmd/plugin-ai` & `docmd-assistant`)

- **自主 MCP 客户端工具套件**：直接在浏览器端为 AI 助手接入了 5 项核心客户端工具：
  - `get_site_structure`：读取完整的站点版本树（当前及历史版本）、语言列表、多项目边界及页面层级。
  - `search_documentation`：支持在文档站点内进行全文检索与语义向量检索。
  - `read_documentation_page`：从任何页面拉取结构化清晰的 Markdown 文本内容。
  - `navigate_to_page`：智能平滑导航访客至目标章节与小节。
  - `copy_code_snippet`：直接提取代码块与命令至访客剪贴板，并带有明确视觉反馈。
- **无截断上下文窗口（默认 200k 字符）**：移除了先前硬编码的 15,000 与 40,000 字符限制，引擎现在将完整的检索文档上下文（默认最高 200,000 字符）传递给大模型，保障技术解释与配置示例的完整性。
- **可配置 `contextWindow`**：在 `plugins.ai` 配置中新增了 `contextWindow`（或 `contextLimit`）参数，方便项目针对特定 Token 配额进行弹性定制。
- **代码块渲染优化**：助手 Markdown 代码块增加了语法高亮、语言徽标以及一键复制按钮。
- **Cloud 中继遥测与日志去重修复**：修复了工具自主循环调用期间将内部多轮检索重复计入 Cloud 查询分析的问题，并彻底清除了长问题中出现的孤立引号前缀。

### Threads 协作讨论插件 (`@docmd/plugin-threads`)

- **Summer 模板原生兼容**：完美支持 Summer 主题，保证固定讨论侧边栏、浮动按钮与身份切换器无缝展示。
- **暗黑模式样式深度优化**：为帖子卡片、评论流、弹出框与行内编辑器提供原生暗黑模式样式覆盖。
- **标题悬停操作体验**：重构了标题旁的 “+ 发起讨论” 按钮，默认隐藏并在鼠标悬停或键盘聚焦时平滑显现，消除视觉干扰。
- **零 CDN 内联 SVG**：以轻量高效的内联 SVG 完全替代 Shoelace CDN 图标，离线与防火墙环境下毫秒加载。

### OpenAPI 插件增强 (`@docmd/plugin-openapi`)

- **多项目工作区路径解析**：优化了在复杂工作区和子项目场景下的规范文件查找（例如子站点目录内的 `assets/docmd-api.json`）。插件现会自动检索当前 Markdown 所在目录、项目边界根目录以及工作区根目录。
- **下载按钮遵守配置**：下载按钮正确遵循 `download: true` 配置，并生成相对于根路径的下载链接。
- **内联 OpenAPI 规范支持**：标记为 ```` ```openapi ```` 的代码块现在可直接解析内联嵌入的 JSON 或 YAML 规范文本，无需依赖独立的外部文件。
- **精确的错误诊断**：当规范文件路径缺失或无法找到时，开发构建期间将显示清晰的 `.oa-error` 提示框。

### 全球多语言文档同步

- **多语言一致性**：在英语 (`en`)、德语 (`de`)、西班牙语 (`es`) 和中文 (`zh`) 之间完全同步了发行说明、Cloud AI 中继指南与导航树。
