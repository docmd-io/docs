### 亮点

`docmd` v0.9.5 增强了在多项目工作区和子目录中对 OpenAPI 规范文件的智能发现，支持在 Markdown 代码块中直接内联嵌入 JSON/YAML 规范，并提供了更精确的错误诊断提示。

### OpenAPI 插件增强 (`@docmd/plugin-openapi`)

- **多项目工作区路径解析**：优化了在复杂工作区和子项目场景下的规范文件查找（例如子站点目录内的 `assets/docmd-api.json`）。插件现会自动检索当前 Markdown 所在目录、项目边界根目录以及工作区根目录。
- **内联 OpenAPI 规范支持**：标记为 ```` ```openapi ```` 的代码块现在可直接解析内联嵌入的 JSON 或 YAML 规范文本，无需依赖独立的外部文件。
- **精确的错误诊断**：当规范文件路径缺失或无法找到时，开发构建期间将显示清晰的 `.oa-error` 提示框。

### 全球多语言文档同步

- **多语言一致性**：在英语 (`en`)、德语 (`de`)、西班牙语 (`es`) 和中文 (`zh`) 之间完全同步了发行说明与导航树。
