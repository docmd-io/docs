### 概述

`docmd` v0.9.0 引入了全新的 **docmd assistant** 引擎，为单项目及多项目工作区环境提供零配置的 AI 文档搜索与交互式对话。本次发布同时带来了上下文页面相对路径路由、离线构建模式以及多项核心引擎稳定性修复。

### AI 助手集成 (`@docmd/plugin-ai`)

原生 AI 文档助手现已正式集成至 `docmd`：

- **docmd Assistant 引擎集成**：由 `docmd-assistant` (v0.1.6) 提供支持，在文档站点中直接提供智能对话与技术答疑。
- **自带密钥 (BYOK)**：支持 OpenAI、Anthropic、Gemini、DeepSeek 与 Ollama 模型，通过 docmd cloud 中继安全传输。
- **云端配置**：通过 [docmd cloud](https://cloud.docmd.io) 为项目配置 AI 助手凭据与参数。
- **多项目工作区 RAG 搜索**：在多项目工作区配置中，助手可跨兄弟项目的搜索索引 (`_docmd-search/search-index.json`) 进行全局文档检索。
- **规范 URL 解析**：自动规范化并解析内部超链接，确保本地预览服务器与子路径生产部署中的链接均能准确跳转。
- **结构化输出渲染**：原生支持 GFM Markdown 表格、内联代码块以及自适应明暗主题界面。

### 上下文导航与 SPA 页面同步

- **页面相对路径路由**：版本、语言与项目切换器优先使用相对路径 (`./`, `../`)，确保在根目录、子路径及本地预览环境下的完全可移植性。
- **SPA 布局动态同步**：顶部导航栏、公告横幅与 Cookie 同意栏在 SPA 页面切换时动态更新，维持任意嵌套层级下的正确链接关系。
- **开发服务器路由修复**：修复了在自定义工作区配置下运行本地开发服务器时的子路径重定向问题。

### CLI 离线构建模式 (`--offline`)

新增 `--offline` CLI 标志，用于构建适用于离线分发的自包含文档包：

- 跳过网络索引与外部数据拉取。
- 强制为相对链接添加 `.html` 后缀，兼容 `file://` 本地文件协议。
- 在搜索界面中注入本地化的离线状态提示。

### 引擎修复与维护

- **核心解析器与引擎修复 (#186, #187, #188, #189, #190)**：修复了 AST 容器解析、路径规范化及插件运行时执行边界相关问题。
- **搜索 Bridge API**：公开 `window.docmdSearch.search` 全局接口，便于客户端 RAG 集成。
- **运行环境要求**：将所有工作区包的最低 Node.js 版本要求提升至 `>=20.0.0`。
