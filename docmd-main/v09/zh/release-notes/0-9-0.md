### 亮点

`docmd` v0.9.0 引入了 **docmd assistant** 引擎，在单项目和多项目工作区环境中提供零配置 AI 文档搜索与交互式问答。本版本还带来了极简 **TUI 界面重构**、严格的 **Cloud 域名来源安全校验**、确保站点完整可移植性的上下文页面相对路由、离线构建模式以及关键引擎稳定性修复。

### 极简 TUI 重构

- **无边框输出**: 从 CLI 执行、开发服务器输出和维护测试管道 (`pnpm prep`) 中完全清除了垂直管道符 (`│`)、框线字符 (`┌─`, `└─`) 和重度视觉干扰。
- **标准化视觉节奏**: 用干净的左对齐视觉层级替换缩进边框，采用加粗大写章节标题和分组之间的标准空行分隔。
- **品牌刷新**: 在所有 CLI 标头中将核心 Logo 品牌更新为鲜艳的蓝色 (`chalk.blue`)。
- **简化插件日志**: 将内部插件（如 OKF）的日志冗长度缩减为干净的单行状态摘要。

### AI 助手与 Cloud 安全 (`@docmd/plugin-ai`)

AI 文档助手现已原生集成到 `docmd` 中：

- **docmd Assistant 引擎**: 由 `docmd-assistant` (v0.1.6) 提供支持，将对话式技术指导直接带入文档站点。
- **严格域名来源校验**: 使用针对项目域名注册的严格 Origin 检查对 Cloud AI 助手中继端点进行加固，防止未经授权的第三方使用。
- **平台管理的 Localhost 开关**: 在 docmd Cloud 仪表板中引入项目级设置，以启用本地预览测试 (`127.0.0.1` / `localhost`)，无需暴露客户端配置参数。
- **自带密钥 (BYOK)**: 支持 OpenAI、Anthropic、Gemini、DeepSeek 和 Ollama 提供商，通过 docmd cloud 中继安全路由。
- **Cloud 配置**: 通过 [docmd cloud](https://cloud.docmd.io) 配置助手凭据和项目设置。
- **多项目工作区 RAG**: 在多项目工作区配置中支持跨同级搜索索引 (`_docmd-search/search-index.json`) 的全局文档发现。
- **规范链接解析**: 在本地预览服务器和子路径生产部署中，自动清理并解析内部超链接至精确站点路径。
- **格式化响应渲染**: 原生支持 GFM Markdown 表格、内联代码块和自适应浅色/深色 UI 主题。

### 上下文导航与 SPA 同步

- **页面相对路由**: 版本、语言和项目切换器现在优先使用相对路径 (`./`, `../`)，确保在根路径、子路径和本地预览环境中的完整站点可移植性。
- **SPA 布局替换**: 顶部菜单栏、公告横幅和 Cookie 同意元素在 SPA 转换期间动态更新，以在任何目录深度维护正确的相对链接。
- **开发服务器路由修复**: 解决了在自定义工作区配置中运行本地开发服务器时的子路径重定向不匹配问题。

### CLI 离线构建模式 (`--offline`)

引入了用于构建适合离线分发的自包含文档包的 `--offline` CLI 标志：

- 绕过搜索索引和外部网络请求。
- 强制添加 `.html` 链接后缀，直接兼容 `file://` 协议。
- 在搜索界面内部注入指示离线状态的本地化通知。

### 引擎与 Bug 修复

- **核心解析器与引擎修复 (#186, #187, #188, #189, #190)**: 修复了 AST 容器解析、路径规范化和插件运行时执行边界方面的问题。
- **搜索 Bridge API**: 暴露 `window.docmdSearch.search` 用于客户端 RAG 集成。
- **Node.js 引擎要求**: 在所有工作区包中将最低 Node.js 要求更新为 `>=20.0.0`。
