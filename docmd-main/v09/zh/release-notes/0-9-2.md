### 核心亮点

`docmd` v0.9.2 为由 `docmd-assistant` v0.1.11 驱动的 `@docmd/plugin-ai` 带来了重大升级，支持确定性的多轮工具执行、基于上下文的事实合成、带独立语言标签栏的现代代码块 UI 以及针对中继端点的流解析容错能力。

### AI 助手插件增强（`@docmd/plugin-ai`）

- **多轮工具执行循环稳定性提升**：升级至 `docmd-assistant` v0.1.11。助手引擎现在能够在多轮自主工具调用（如 `search_documentation`、`get_site_structure`）过程中确定性地保留用户上下文与查询意图，确保最终合成轮次严格依据检索到的文档事实生成带有可点击 Markdown 链接的答案。
- **现代化代码块 UI**：重新设计了 AI 聊天界面内的代码块渲染：
  - 代码片段封装在专用的 `.docmd-ai-code-wrap` 容器内。
  - 独立的语言标头栏（`.docmd-ai-code-header > .docmd-ai-code-lang`）清晰展示编程语言标签（如 `bash`、`typescript`、`json`），避免污染 `<pre><code>` 内的命令文本。
- **Markdown 格式化与段落换行修复**：修复了 Markdown 格式化过程中代码块占位符被视作行内文本的问题，消除了代码块和列表周围多余的 `<p>` 和 `<br/>` 标签。
- **HTTP 流与 JSON 回退容错**：助手客户端现在透明兼容来自中继后端的 Server-Sent Events（`text/event-stream`）流与非流式 JSON 响应，有效防止在代理或 Serverless 部署环境下出现 “No response returned” 报错。
- **TypeScript 类型定义**：修正了 `@docmd/plugin-ai` 各生命周期钩子中隐式的 `any` 参数类型。

### 全局文档多语言对齐

- **多语言同步**：所有发布说明与助手相关文档已在中文（`zh`）、英文（`en`）、德文（`de`）和西班牙文（`es`）之间实现 1:1 完整同步。
