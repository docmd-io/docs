### Highlights

`docmd` v0.9.6 delivers universal container `title` property support across tag and button containers, protocol-safe URL parsing for container headers, a KaTeX math multiline preset fix in the live server preview, an upgrade to `lucide-static` v1.43.0, and documentation consistency improvements.

### Universal Container Syntax & Header Normalisation (`@docmd/parser`)

- **Tag & Button Named `title` Support**: Full support for named `title:"..."` attributes in `::: tag` and `::: button` containers, matching the standard container specification introduced in v0.9.1. Backward compatibility for positional strings and bare words is strictly preserved.
- **Protocol-Safe Key-Value Parsing**: Added negative lookahead protection for standard URL protocols and link prefixes (`https:`, `http:`, `mailto:`, `tel:`, `external:`, `raw:`). Positional URLs and external links are no longer misidentified as named container keys.
- **Changelog Item Properties**: `::: log` entries in changelog containers now support named `title:"..."` and `version:"..."` properties in addition to positional version strings.
- **Tooltip Explanation Failsafe**: `::: tip` and `::: tooltip` now accept `title:` as a seamless failsafe alias for `text:` in hover popover explanations.
- **Open Attribute Parity for `::: details`**: The `::: details` migration alias now supports the `open` keyword identically to `::: collapsible open`.

### Live Server KaTeX Math Rendering (`@docmd/live`)

- **Preserved Block Equation Delimiters**: Fixed an issue in the preset template bundler where `String.prototype.replace()` treated `$$` delimiters in preset Markdown as replacement patterns, collapsing block equations (`$$...$$`) into invalid inline syntax (`$...$`). Multiline KaTeX equations now render accurately in live presets.

### Icon Library Update (`@docmd/parser`)

- **Lucide Icons Upgrade**: Updated `lucide-static` to `^1.43.0`, introducing new icons and stroke refinements across all container headers, cards, buttons, and badges.
