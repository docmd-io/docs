### Highlights

`docmd` v0.9.3 delivers offline air-gapped Mermaid bundling ([Issue #198](https://github.com/docmd-io/docmd/issues/198)), OpenAPI request/response examples and schema layout containment ([Issue #199](https://github.com/docmd-io/docmd/issues/199), [PR #200](https://github.com/docmd-io/docmd/pull/200)), universal AI Assistant tool-call parsing powered by `docmd-assistant` v0.1.14 ([Issue #206](https://github.com/docmd-io/docmd/issues/206)), URL sanitisation stability enhancements ([PR #203](https://github.com/docmd-io/docmd/pull/203)), and CI pipeline verification stabilization ([Issue #205](https://github.com/docmd-io/docmd/issues/205)).

### Offline & Air-Gapped Mermaid Diagrams (`@docmd/plugin-mermaid`)

- **Local Self-Contained Bundling ([Issue #198](https://github.com/docmd-io/docmd/issues/198))**: The Mermaid plugin now bundles the entire Mermaid runtime locally using `esbuild` as a classic IIFE script, completely removing runtime CDN dependencies (`jsdelivr.net`).
- **Air-Gapped & `file://` Compatibility**: Diagrams now render completely offline, in zero-network air-gapped environments, and when viewing compiled documentation directly through the `file://` protocol without triggering browser CORS policy blocks.

### OpenAPI Plugin Enhancements (`@docmd/plugin-openapi`)

- **Examples & Media Types ([Issue #199](https://github.com/docmd-io/docmd/issues/199), [PR #200](https://github.com/docmd-io/docmd/pull/200))**: Added comprehensive support for OpenAPI 3.x request body examples, response examples, and multi-schema sample bodies contributed by [@w666](https://github.com/w666).
- **Schema Table Containment & Horizontal Scrolling**:
  - Wrapped parameter and schema tables in `.oa-table-wrap` containers with isolated `overflow-x: auto` scrolling.
  - Expanding deep schema trees or complex nested tables no longer causes page-level viewport distortion or horizontal blowout.
  - Operation headers, method badges, summaries, and descriptions remain stably positioned with word-break wrapping.

### AI Assistant Plugin & Engine (`@docmd/plugin-ai` & `docmd-assistant` v0.1.14)

- **Universal Multi-Format Tool Parser ([Issue #206](https://github.com/docmd-io/docmd/issues/206))**: Upgraded `docmd-assistant` with universal tool-call extraction handling balanced JSON objects, Markdown codeblocks (` ```json `), bracketed syntax (`[Tool Call: name(...)]`), and zero-argument calls (`get_site_structure()`).
- **Zero Raw String Leakage**: Guarantees raw tool-call strings are never exposed in user chat; tools are executed autonomously and synthesised into clean, fact-grounded explanations.
- **Classic Script Execution**: Client assets now compile as classic IIFE scripts, ensuring compatibility with offline `file://` browsing.

### Parser & Core Fixes (`@docmd/parser` & `@docmd/core`)

- **URL Sanitisation ([PR #203](https://github.com/docmd-io/docmd/pull/203))**: Fixed leading `//` protocol-relative collapse in `sanitizeUrl` preventing broken links in generated sub-sites, contributed by [@eeshsaxena](https://github.com/eeshsaxena).
- **CI Verification Pipeline Stabilization ([Issue #205](https://github.com/docmd-io/docmd/issues/205))**: Resolved an unstable test assertion in project switcher URL contracts and added cross-platform browser options (including Firefox) to the bug report template.
- **Service Worker Protocol Guard**: Added protocol checks ensuring `navigator.serviceWorker` registration queries are safely bypassed on `file://` origins without throwing security exceptions.
