### Highlights

`docmd` v0.9.5 delivers enhanced OpenAPI specification discovery across multi-project workspaces and subdirectories, direct support for inline JSON/YAML specs in markdown code fences, and improved error diagnostics.

### OpenAPI Plugin Enhancements (`@docmd/plugin-openapi`)

- **Multi-Project Workspace Resolution**: Resolved specification file lookup in complex workspaces and subprojects (e.g. `assets/docmd-api.json` within sub-site directories). The plugin now checks the active markdown file's directory, project boundary root, and workspace root automatically.
- **Inline OpenAPI Specifications**: Fenced blocks tagged with ```` ```openapi ```` now directly accept raw JSON or YAML OpenAPI specifications embedded in the markdown file without requiring a separate external file.
- **Robust Error Diagnostics**: Missing or invalid spec paths now surface clear, contextual `.oa-error` callouts in development builds instead of silent rendering fallbacks.

### Global Documentation Parity

- **Multilingual Synchronisation**: Synchronised release notes and navigation trees across English (`en`), German (`de`), Spanish (`es`), and Chinese (`zh`).
