`docmd-assistant` v0.1.3 führt vollständige Seitenlesefunktionen, benutzerdefinierte Reader-Callbacks und standardisierte Reasoning-Optionen ein.

## Hauptmerkmale & Verbesserungen

### Werkzeug zum Lesen vollständiger Seiten (`read_documentation_page`)

`read_documentation_page` wurde zu `createStandardTools()` hinzugefügt. Wenn Suchergebnisse nicht ausreichen, kann der Assistent den vollständigen Seitentext abrufen.

### Benutzerdefinierter Reader-Callback

`createStandardTools()` akzeptiert jetzt ein zweites Callback-Argument (`customReader`):

```typescript
const tools = createStandardTools(
  customSearchCallback,
  async (path) => {
    const res = await fetch(`/api/page?path=${encodeURIComponent(path)}`);
    return await res.json();
  }
);
```
