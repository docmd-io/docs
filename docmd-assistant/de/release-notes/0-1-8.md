`docmd-assistant` v0.1.8 führt dedizierte Dokumentations-Werkzeuge (`get_site_structure`, `search_documentation`), eine Nebenläufigkeitssperre auf Engine-Ebene, Relay-Tool-Weiterleitung und clientseitige Werkzeugausführung ein.

## Hauptfunktionen & Verbesserungen

### Dedizierte Dokumentations-Werkzeuge

v0.1.8 standardisiert Kernwerkzeuge speziell für Dokumentationsseiten:

- **`get_site_structure`**: Liefert die vollständige Seitenhierarchie einschließlich aktiver und historischer Dokumentationsversionen, unterstützter Sprachversionen (i18n), Multi-Projekt-Topologien, Suchfunktionen und Navigationsbäumen. Ermöglicht präzise Antworten auf strukturelle und versionsbezogene Anfragen ohne Halluzinationen.
- **`search_documentation`**: Bietet Volltext-Stichwortsuche und optionale semantische Vektorsuche über alle Workspace-Projekte hinweg. Filtert Ergebnisse automatisch nach aktiver Version und Sprache, um veraltete oder fremdsprachige Inhalte auszuschließen.

```typescript
engine.registerTool({
  name: 'get_site_structure',
  description: 'Dokumentationsversionen, Sprachen, Workspace-Projekte und Navigationsbäume abrufen.',
  execute: async () => {
    return getSiteMetadata();
  }
});

engine.registerTool({
  name: 'search_documentation',
  description: 'Dokumentationsseiten über Projekte hinweg durchsuchen.',
  execute: async ({ query, project }) => {
    return await searchIndexes(query, project);
  }
});
```

### Nebenläufigkeitssperre auf Engine-Ebene

`DocmdAssistantEngine.sendMessage()` verfügt nun über eine interne Ausführungssperre (`isExecuting`). Parallele Anfragen werden sauber abgefangen, bis der aktuelle Antwortzyklus abgeschlossen ist.

### Relay-Tool-Weiterleitung & Ausführung

Im Relay-Modus überträgt `runRelayTurn` nun automatisch registrierte Werkzeugschemata im Anfrage-Payload. Wenn das Relay Werkzeugaufrufe zurückgibt, führt die Engine diese lokal aus und sendet die Ergebnisse nahtlos zurück.

### Professionelle & prägnante Systemprompts

Die Standard-Systemprompts wurden für präzise, professionelle und direkte Dokumentationsantworten mit minimalem Emoji-Einsatz optimiert.
