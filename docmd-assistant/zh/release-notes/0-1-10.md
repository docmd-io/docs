`docmd-assistant` v0.1.10 引入了支持实时流传输的多轮自主工具执行循环、健壮的工具参数规范化解析，以及用于防止状态竞态条件的并发锁。

## 主要功能与改进

### 自主工具执行与实时流传输

- **多轮工具执行**: 在直接 `aiplug` 模式和自定义 Relay 模式下均实现了多轮工具执行循环，使引擎能够自动运行已注册的工具（例如文档搜索）并将结果反馈给 LLM。
- **实时流传输支持**: 启用 `sendMessageStream` 和流式 Relay 适配器，支持由工具驱动并伴随实时状态回调的回答输出。

### 健壮的工具参数规范化

- **灵活解析**: 规范了工具参数的解析，可无缝处理各种大模型输出格式——支持原始 JSON 字符串、嵌套的 `arguments`/`input` 对象以及直接的参数键值对。
- **容错异常处理**: 将工具执行封装在安全边界内，确保在工具发生错误时将结构化错误信息返回给模型，而不会导致整个对话循环崩溃。

### 并发保护与 UI 状态事件

- **并发锁机制**: 为 `sendMessage` 和 `sendMessageStream` 添加了运行并发锁，防止连续快速提交多个查询时发生状态竞争。
- **状态事件与徽章**: 发送细粒度的 `status` 事件（例如 `"正在搜索文档..."`、`"正在思考..."`），在多步骤工具执行过程中向用户提供即时反馈。
