`docmd-assistant` v0.1.8 引入了专属文档内省工具（`get_site_structure` 与 `search_documentation`）、引擎层并发请求锁、Relay 模式工具转发以及客户端工具调用执行能力。

## 主要更新项

### 专属文档内省工具

v0.1.8 规范化并强化了专为文档站点设计的核心工具接口：

- **`get_site_structure`**：返回完整的站点结构拓扑，包括当前与历史文档版本、多语言（i18n）支持、多项目工作区配置、搜索引擎能力以及页面导航树结构。使 AI 助手无需猜测即可精准解答结构和版本问题。
- **`search_documentation`**：跨工作区项目提供全文关键词搜索与条件语义向量搜索能力。自动依据当前激活的文档版本与语言环境进行过滤与相关性排序，彻底杜绝历史版本或异构语言内容干扰。

```typescript
engine.registerTool({
  name: 'get_site_structure',
  description: '获取文档版本、多语言、工作区项目及完整导航树结构。',
  execute: async () => {
    return getSiteMetadata();
  }
});

engine.registerTool({
  name: 'search_documentation',
  description: '跨项目搜索文档内容。',
  execute: async ({ query, project }) => {
    return await searchIndexes(query, project);
  }
});
```

### 引擎层并发控制锁

`DocmdAssistantEngine.sendMessage()` 内置了执行状态锁 (`isExecuting`)。当已有消息正在生成时，阻止并发请求提交，彻底避免状态竞争与数据冲突。

### Relay 模式工具转发与执行支持

在 Relay 模式下，`runRelayTurn` 现已自动携带已注册工具的 Schema 参数。若中继端返回工具调用请求，引擎可在客户端执行并透明回传结果。

### 专业精简的提示词架构

默认系统提示词进行了全方位优化，精简冗余表情符号与客套话，提供直接、清晰且高专业度的文档解答体验。
