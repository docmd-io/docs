`docmd-assistant` v0.1.19 将核心生态依赖升级至 `aiplug` v0.2.0，全面迁移至 TypeScript 7 与 Node 26 类型定义，并新增运行时版本导出。

## 核心功能与重大改进

### 生态与依赖升级

- **集成 aiplug v0.2.0**：升级底层 LLM 编排层至 `aiplug` v0.2.0，增强连接池复用与多模型提供商兼容性。
- **TypeScript 7 与 Node 26 类型**：构建工具链升级至 TypeScript 7（`^7.0.2`），Node 类型定义升级至 `@types/node`（`^26.6.6`），并在 `tsconfig.json` 中配置显式 `"types": ["node"]`。

### 运行时版本检测

- **导出 `ENGINE_VERSION`**：直接从 `docmd-assistant` 导出 `ENGINE_VERSION` 常量，便于下游客户端与插件在运行时以编程方式检查引擎版本。
