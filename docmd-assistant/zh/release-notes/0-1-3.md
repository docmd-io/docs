`docmd-assistant` v0.1.3 引入了完整的页面读取功能、自定义读取器回调、标准化的推理选项和提示词引用规则。

## 主要特性与改进

### 全页面读取工具 (`read_documentation_page`)

向 `createStandardTools()` 添加了 `read_documentation_page`。当搜索片段缺乏足够的详细信息时，助手可以从特定的文档页面路径获取并提取正文文本与代码块。

### 自定义读取器回调

`createStandardTools()` 现在接受第二个回调参数 (`customReader`)，允许开发者接入自定义页面加载器（例如 Headless CMS API、原始 Markdown 文件或数据库查询）：

```typescript
const tools = createStandardTools(
  customSearchCallback,
  async (path) => {
    const res = await fetch(`/api/page?path=${encodeURIComponent(path)}`);
    return await res.json();
  }
);
```

### 标准化推理参数

更新了 `reasoning` 配置选项模式，以支持针对推理模型的高颗粒度级别控制 (`false`, `'low'`, `'medium'`, `'high'`)。
