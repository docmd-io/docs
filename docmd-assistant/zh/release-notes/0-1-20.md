`docmd-assistant` v0.1.20 引入了一套扩展自定义 API 钩子（`formatToolResult`、`compactHistory`、`transformContext`、`onPayload`），以实现对上下文和对话历史的精细化控制，并增加网络 Relay 失败时的原子化历史回滚，彻底杜绝历史状态残留。

## 核心功能与重大改进

### 扩展 API 自定义钩子

- **`formatToolResult` 钩子**：允许上层应用在工具结果注入上下文前，对其进行领域定制化的格式化、摘要提取或高信号截取。
- **`compactHistory` 钩子**：支持下游客户端与插件根据需求紧缩历史记录，压缩早期对话轮次或过大的工具输出，保持最佳 Token 效率。
- **`transformContext` 钩子**：在向 LLM 或云中继（Cloud Relay）分发之前，对中间上下文边界进行精细裁剪与边界保护。
- **`onPayload` 钩子**：允许在网络请求发送前即时检查、微调或装饰载荷字段。

### 高可靠性对话状态管理

- **Relay 错误原子化历史回滚**：当云中继请求遭遇网络异常或 4xx/5xx 报错时，系统会自动将尚未成功的用户待处理消息从内部历史中干净回滚，防止后续提问因残留的历史消息而持续失败。
