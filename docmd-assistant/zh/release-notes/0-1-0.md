**`docmd-assistant` v0.1.0** 的初始版本发布，这是一个通用、框架无关的 Headless AI 助手引擎，专为软件文档工具和 Web 应用程序打造。

## v0.1.0 包含的功能

### Headless 引擎架构

- **`DocmdAssistantEngine`**: 管理逐轮对话、状态历史和动态系统 Prompt 的核心类。
- **纯逻辑设计**: 与 UI 框架解耦，核心分发中不渲染任何 DOM 元素。

### 多 Provider 与多模型支持

- 与 `aiplug` 多 Provider 运行时直接集成。
- 支持 OpenAI, Anthropic, Gemini, DeepSeek, Groq, MiniMax, Ollama 和自定义基础端点。

### 可扩展的工具管道

- 使用 JSON Schema 参数定义注册自定义工具。
- 自动工具调用执行与上下文循环解析。
- 标准工具辅助函数，用于文档搜索、锚点跳转、代码复制和页面读取。

### 事件模型与订阅

- 事件订阅接口 (`on`/`off`)，用于消息发送、工具调用和错误处理。
