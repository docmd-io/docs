`docmd-assistant` v0.1.9 引入了全方位的 LLM 输出结果净化机制、主动且自主的工具调用搜索执行、智能版本与语言环境相关性提权，以及本地和 Relay 运行环境下的会话流状态增强。

## 主要更新项

### LLM 输出净化与多余标记剔除

`cleanAssistantReply()` 现可强力剔除模型推理思考块（`<think>`、`<mm:think>`）、原始工具调用 XML 标记（`<tool_call>`、`<request>`）以及各模型服务商的内置元数据包装器，确保向用户呈现干净专业的回答：

```typescript
import { cleanAssistantReply } from 'docmd-assistant';

const clean = cleanAssistantReply(rawModelOutput);
```

### 主动式工具执行与自主搜索

系统提示词与执行管线现已强制要求在处理技术性、版本及发布说明类问题时主动执行工具：

- **告别重复询问**：助手会直接调用 `search_documentation` 或 `get_site_structure` 获取准确的文档事实，绝不反复向用户询问“是否需要我帮您搜索”。
- **版本与补丁智能检索**：针对查询最新版本或补丁更新说明（如 `v0.9.1`）的问题，自动检索发布说明，避免仅依赖静态版本分支名称造成误判。

### 版本作用域排序与过滤优化

- **当前版本结果提权**：增强了搜索结果的相关度打分逻辑，优先呈现与当前激活的文档分支及语言相匹配的文档。
- **历史归档内容自动降权/排除**：默认排除旧版本的文档干扰，除非用户明确询问历史版本。

### 会话状态流稳定性强化

- 强化了 `runRelayTurn` 与 `runAiplugTurn` 中的轮次与消息状态管理。
- 完善了网络波动与 Relay 中继中断时的边界保护与错误恢复机制。
