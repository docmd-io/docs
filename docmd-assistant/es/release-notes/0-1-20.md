`docmd-assistant` v0.1.20 introduce ganchos de personalización de API extendida (`formatToolResult`, `compactHistory`, `transformContext`, `onPayload`) para una gestión granular del contexto y el historial, y proporciona reversión atómica del historial para evitar la corrupción de estado ante fallos de red en el relay.

## Características Principales y Mejoras

### Ganchos de Personalización de API Extendida

- **Gancho `formatToolResult`**: Permite a las aplicaciones formatear, resumir o filtrar datos clave de los resultados crudos de ejecución de herramientas antes de inyectarlos en el contexto del asistente.
- **Gancho `compactHistory`**: Permite a clientes y plugins personalizar la compactación del historial de chat, resumiendo turnos anteriores o salidas extensas de herramientas para una eficiencia óptima de tokens.
- **Gancho `transformContext`**: Proporciona control preciso sobre los límites del contexto intermedio inmediatamente antes de enviarlo a proveedores LLM o relays en la nube.
- **Gancho `onPayload`**: Permite inspeccionar, modificar o complementar las cargas de solicitud de red directamente antes de su transmisión.

### Gestión Resiliente del Estado de Conversación

- **Reversión Atómica del Historial ante Errores de Relay**: Si una solicitud de relay falla (por ejemplo, errores 4xx/5xx o desconexiones de red), la consulta pendiente del usuario se retira limpiamente del historial interno, garantizando que los mensajes posteriores no fallen repetidamente con un historial corrupto.
