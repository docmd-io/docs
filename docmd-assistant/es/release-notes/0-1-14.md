`docmd-assistant` v0.1.14 introduce un analizador universal de llamadas a herramientas que intercepta y ejecuta con precisión las invocaciones de herramientas de IA en todos los modelos y formatos de salida.

## Características Principales y Mejoras

### Analizador Universal Multiformato de Herramientas

- **Escáner JSON Equilibrado**: Extrae con fiabilidad objetos JSON independientemente del orden de las claves (`{"name": ..., "parameters": ...}` o `{"parameters": ..., "name": ...}`), estructuras anidadas o cargas de argumentos codificadas como cadenas.
- **Análisis de Bloques de Código Markdown**: Detecta y extrae cargas útiles dentro de bloques de código Markdown estándar (````json ... ````, ````tool_call ... ````).
- **Sintaxis entre Corchetes**: Extracción completa para expresiones etiquetadas:
  - `[Tool Call: search_documentation({"query":"..."})]`
  - `[Tool Call: get_site_structure()]`
  - `[TOOL_CALL: search_documentation(...)]`
  - `[Function Call: name(...)]`
- **Sintaxis Funcional y sin Argumentos**: Soporte para llamadas sin argumentos (`get_site_structure()`) y listas de argumentos funcionales (`tool_name(query="value")`).

### Coincidencia Dinámica de Herramientas Registradas

- **Integración con el Registro**: Los bucles de ejecución del motor pasan directamente los nombres de las herramientas registradas (`search_documentation`, `get_site_structure` y herramientas personalizadas) a `parseAssistantOutput` para una detección determinista.

### Cero Fuga de Cadenas de Herramientas en el Chat

- **Experiencia de Usuario Limpia**: Evita totalmente que el texto de llamada a herramientas sin procesar aparezca en el chat del usuario; todas las invocaciones se ejecutan de forma autónoma y se transforman en respuestas explicativas claras y fundamentadas.
