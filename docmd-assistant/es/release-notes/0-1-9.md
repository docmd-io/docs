`docmd-assistant` v0.1.9 introduce una sanitización integral de las respuestas de LLM, ejecución proactiva y autónoma de herramientas de búsqueda, filtrado y ponderación por versión/idioma y mayor estabilidad en el flujo de chat.

## Características Principales y Mejoras

### Sanitización de Salida LLM y Eliminación de Artefactos

`cleanAssistantReply()` elimina de forma rigurosa los bloques de razonamiento/pensamiento (`<think>`, `<mm:think>`), etiquetas XML de llamadas a herramientas (`<tool_call>`, `<request>`) y metadatos internos del proveedor antes de guardar o renderizar los mensajes:

```typescript
import { cleanAssistantReply } from 'docmd-assistant';

const clean = cleanAssistantReply(rawModelOutput);
```

### Ejecución Proactiva de Herramientas y Búsqueda Autónoma

El prompt del sistema y la canalización de ejecución ahora exigen el uso autónomo de herramientas en consultas técnicas, de versiones y de notas de lanzamiento:

- **Sin Bucles de Permisos**: El asistente ejecuta directamente `search_documentation` o `get_site_structure` para obtener hechos exactos en lugar de pedir confirmación al usuario ("¿Desea que busque?").
- **Inteligencia en Notas de Versión y Parches**: Realiza búsquedas específicas ante consultas sobre las últimas versiones o notas de parches (p. ej. `v0.9.1`) sin limitarse a la etiqueta de rama estática.

### Ponderación de Versiones y Optimización de Filtros

- **Priorización de la Versión Activa**: Mayor puntuación de relevancia para documentos que coincidan con la rama de versión activa y el idioma actual.
- **Exclusión de Contenido Obsoleto**: Excluye automáticamente ramas de documentación históricas a menos que el usuario las solicite explícitamente.

### Mayor Estabilidad en el Estado del Chat

- Seguimiento interno reforzado en `runRelayTurn` y `runAiplugTurn`.
- Sincronización garantizada de mensajes y gestión de errores ante interrupciones de relay.
