`docmd-assistant` v0.1.3 introduce capacidades de lectura de páginas completas, callbacks de lectura personalizados y opciones de razonamiento estandarizadas.

## Características Principales y Mejoras

### Herramienta de Lectura de Páginas Completa (`read_documentation_page`)

Se añadió `read_documentation_page` a `createStandardTools()`. Cuando los fragmentos de búsqueda carecen de detalle, el asistente puede obtener el texto completo de la página.

### Callback de Lectura Personalizado

`createStandardTools()` acepta ahora un segundo argumento de callback (`customReader`):

```typescript
const tools = createStandardTools(
  customSearchCallback,
  async (path) => {
    const res = await fetch(`/api/page?path=${encodeURIComponent(path)}`);
    return await res.json();
  }
);
```
