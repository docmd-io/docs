## v0.1.6 — 页面读取降级支持

基于 DOM 的页面读取降级机制，支持自动上下文提取。

### 主要更新项

- 优化核心 API 稳定性与性能表现。
- 增强错误捕获与日志诊断信息。
- 完整兼容 TypeScript 类型声明。
