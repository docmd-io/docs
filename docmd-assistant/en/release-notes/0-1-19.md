`docmd-assistant` v0.1.19 updates core ecosystem dependencies to `aiplug` v0.2.0, upgrades to the TypeScript 7 toolchain with Node 26 type definitions, and introduces a runtime version export.

## Key Features & Enhancements

### Ecosystem & Dependency Upgrades

- **aiplug v0.2.0 Integration**: Upgraded the underlying LLM provider orchestration layer to `aiplug` v0.2.0, improving connection pooling and provider compatibility.
- **TypeScript 7 & Node 26 Types**: Upgraded build toolchain to TypeScript 7 (`^7.0.2`) and Node type definitions to `@types/node` (`^26.6.6`) with explicit `"types": ["node"]` configuration in `tsconfig.json`.

### Runtime Version Introspection

- **Exported `ENGINE_VERSION`**: Exported `ENGINE_VERSION` constant directly from `docmd-assistant`, enabling client applications and plugins to inspect the active assistant engine version programmatically at runtime.
