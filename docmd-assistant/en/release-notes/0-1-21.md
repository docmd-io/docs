`docmd-assistant` v0.1.21 introduces the `fetchExternalUrls` configuration option, enabling the assistant engine and the `read_documentation_page` tool to fetch, parse, and synthesize content from external documentation websites via HTTP/HTTPS relays.

## Key Features & Enhancements

### External URL Fetching Support

- **`fetchExternalUrls` Option**: Added `fetchExternalUrls?: boolean` to `AssistantOptions` and the `isFetchExternalUrlsEnabled()` engine query method. When enabled, the assistant is permitted to load and inspect documentation hosted outside the local site origin.
- **`read_documentation_page` Tool Enhancement**: Extended parameter descriptions and URL parsing to accept fully-qualified HTTP/HTTPS URLs (`https://...`). Automatically normalizes paths, extracts structured main content, strips chrome and navigational noise, preserves code blocks, and applies token-economic length capping (8,000 characters).
- **Relay & Security Hardening**: Safely guards against arbitrary network calls when external fetching is disabled, ensuring strict origin boundaries unless explicitly opted into by site configuration.
