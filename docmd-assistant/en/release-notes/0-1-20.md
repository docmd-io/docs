`docmd-assistant` v0.1.20 introduces extended customisation API hooks (`formatToolResult`, `compactHistory`, `transformContext`, `onPayload`) for granular context and history management, and provides atomic history rollback to prevent conversation state corruption on relay network failures.

## Key Features & Enhancements

### Extended API Customisation Hooks

- **`formatToolResult` Hook**: Enables applications to format, summarize, or extract high-signal snippets from raw tool execution results before they enter the assistant context.
- **`compactHistory` Hook**: Allows downstream consumers and plugins to customise conversation history compaction, summarizing older turns or large tool results to maintain optimal token efficiency.
- **`transformContext` Hook**: Provides fine-grained control over intermediate synthesis context boundaries right before dispatch to LLM providers or cloud relays.
- **`onPayload` Hook**: Allows inspecting, modifying, or decorating network request payloads prior to transmission.

### Resilient Conversation State Management

- **Atomic History Rollback on Relay Errors**: When a network relay request fails (such as 4xx/5xx responses or network disconnections), the user's pending query is cleanly rolled back from the internal conversation history, ensuring subsequent messages do not fail repeatedly with dangling or corrupted history.
