`docmd-assistant` v0.1.18 expands the multi-turn reasoning budget to 6 turns, introduces a real-time streaming replacement protocol (`meta.replace: true`) for live tokens, and adds architectural context synthesis fallbacks.

## Key Features & Enhancements

### Multi-Turn Reasoning Budget Expansion

- **Extended Turn Ceiling**: Increased the maximum conversation turn ceiling to 6 turns (`maxTurns = 6`), allowing tool-assisted investigations (such as searching site structure, inspecting navigation, and reading specific documentation pages) to complete thoroughly without premature tool cutoff.
- **Guaranteed Final Synthesis**: Tools remain active across intermediate turns and are selectively disabled only on the final turn to guarantee clean synthesis.

### Real-Time Streaming Replacement Protocol

- **Unblocked SSE Token Streaming**: Tokens stream immediately across intermediate turns without suppression, emitting `{ replace: true }` markers when transitioning between reasoning iterations.
- **In-Place Live UI Editing**: Downstream chat clients can smoothly overwrite preliminary thought markers or intermediate summaries with final synthesized responses in real time.

### Architectural Context Synthesis Fallback

- **Multi-Tier Context Synthesiser**: When tool searches yield no dedicated documentation page, the engine automatically synthesises answers by referencing overarching project architecture, layout, and configuration conventions.

## Resolved Issues

- **Premature Tool Cutoff**: Resolved an issue where multi-step queries (such as asking how to reorder navigation or locate specific settings) halted tool execution prematurely.
- **Stream Suppression**: Fixed an issue where live SSE streaming deltas were suppressed while tools were active.
